## 3. B_h 的计划实现

| 指标 | 结果 |
| --- | --- |
| 结构通过（所有组同句＋所有边界分开＋关系对＋无遗漏） | **4/12**（`fixture-r5` `t03` `t24` `v21`） |

**计划响应（4 个 dev 源，P1/P2 两份合法分组）**：

| 源 | P1 vs P2 输出 | 是否随计划改变 |
| --- | --- | --- |
| `t11` | 逐字相同 | 否 |
| `v09` | 逐字相同 | 否 |
| `v17` | 逐字相同 | 否 |
| `fixture-r4` | 逐字相同 | 否 |

**0/4**，低于预定的 3/4 门槛。两份 prompt 只差计划那一行（t11 为 375 vs 388 token，都在 512 以内，没有被截断），模型看得到计划但没有用。

一个直接例子（`t11`）：

```
P1 计划：[f0,f1] ／ [f2,f3]
P2 计划：f0 ／ f1 ／ f2 ／ f3

两次输出都是：
沈砚从潮生巷走到旧灯塔,叶知微把灯罩擦得透亮,沈砚换好塔顶的灯芯,叶知微的袖口沾了铜油。
```

“合并检查为真”在这里没有意义：整段就是一句，什么计划都“合并”。只有边界检查能抓到问题，而边界检查失败了。

## 4. A/B_h 逐源表达得失

按人工读正文的偏好计：**B_h 更好 7 源，A 更好 2 源，两臂都差/相当 3 源**。

| 偏好 | 源 | 理由 |
| --- | --- | --- |
| B_h | `t03` `t24` `train-r4` `train-r5` `v14` `v21` `v23` | B_h 少重复、句子完整；A 在这些源里重复或漏事实 |
| A | `fixture-r5` `v24` | A 没有新增错误事件/重复；B_h 分别多写错误事件、重复“解开钟绳” |
| 都差/相当 | `t08` `v05` `v20` | 两臂都有串主体、漏事实或字段化表达 |

A 的选中检查点只训练了 18 次更新，重复明显（如 `train-r4` 的“围巾”11 次、`t03` 的三次“袖口铜油”）。B_h 的 90 次更新更充分，所以上面的表达偏好**不能全部归给计划**；这是曝光差和训练量共同作用的结果。

B_h 的表达也不是干净通过：`fixture-r5` 重复错误事件、`t08` 串主体、`v24` 重复。表达改善不能抵消这些事实错误。

## 5. 这次说明什么

1. **计划没有被使用**。4/4 响应源在 P1/P2 下逐字相同；边界实现只有 4/12 结构通过，关系 1/3。按预登记，这是“模型没有使用交接”，先查材料/训练，不宣布接口无效。
2. **为什么没被使用**：训练目标的分组和“事实的默认分组”一致（同主体就合并、跨主体就分开），计划在训练里是冗余的；P2 那种“全部拆开”的反事实分组没有出现在任何训练目标里，模型没有学过按任意计划改分组。
3. **A/B_h 的差不能归给计划**：A 选中 18 次更新、B_h 选中 90 次，曝光不同；B_h 在事实（6/12 对 2/12）和表达（7/12 偏好）上更好，但这是“训练更久＋目标更干净”的混合结果。
4. **没有人工参考正文**，不能拿逐字匹配率、loss 或模板复现当表达质量；上表是逐条读正文的相对判断，不是质量验收。

**本轮结论**：这次材料、计划和成句训练下，没有显示计划被成句模型使用；B_h 相对 A 的事实/表达优势与曝光差混在一起。不能据此说“组织→成句”接口无效，也不能说它有效。

补充：A 的 `train-r4` 是唯一一个触顶 128 token 的留出输出（结尾停在“泥”），它的 f3/f4 属于未完成，不是正常结束后的遗漏；A 的正常遗漏是 8 条。结束状态与补评见第 8 节。

## 8. 同更新次数补评（A15，90 次更新）

原始运行没有保存 A epoch 15 的权重；按同 seed/数据/配置复现到 epoch 15，dev 指标与原始日志逐位相同（dev_loss 0.3581，dev_fact 0.875），再生成 12 条留出输出。B_h 没有重跑，仍用原 epoch 15 结果。

- 结束状态：A 选中版 11 EOS／1 触顶（`train-r4`）；B_h 12 EOS／0 触顶；计划响应 8 EOS／0；A15 12 EOS／0。
- 同更新（90 对 90）人工事实通过：A15 **4/12**，B_h **6/12**（A3 时是 2/12）。
- 计划结构通过：A15 **3/12**，B_h **4/12**；关系两边都是 1/3。
- 表达偏好：A15 更好 3 源，B_h 更好 4 源，相当/都差 5 源；对 A3 时 B_h 是 7 对 2，净优势从 +5 缩到 +1。
- 计划响应仍是 **0/4**；A15 没有计划块，不能测。
- A15 在 `fixture-r5` 上没有计划也做对了分组和“随后”，说明这些材料的分组与关系可由事实＋授权关系本身提示，计划不是必要条件。
