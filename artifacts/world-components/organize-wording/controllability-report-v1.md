# 计划可控性 v1 结果（一次训练，冻结后执行）

状态：材料、预算、选点规则先冻结，训练一次；只训练成句模块，没有 A 臂，没有组织模型，没有扫参数。固定留出只跑一次。

- 材料：`controllability-v1.jsonl`，36 源，20 train / 6 dev / 10 固定留出；每源 A（原分组）与 B（全拆）两份计划，目标共用事实短句，B 只改分组、句界和补回姓名。
- 冻结：`controllability-freeze-v1.json`；材料 sha256 `08b23367815297cb05adc9cb096ffd6e21684f56342dbc79ece345e3f73930c0`。
- 训练：Randeng-T5-77M，40 步/epoch，梯度累积 4，12 epoch＝**120 次更新**；dev 成对成功选点，并列取低 loss；跑满 12 epoch。
- 选中：**epoch 9（90 次更新）**，dev 成对成功 **0/6**，dev loss 0.1673。12 个 epoch 的 dev 成对成功都是 0/6；选点是“全零成功里 loss 最低”，不是找到了可用检查点。

## 2. 实际观察

1. **模型没有按 A 换组织方式。** 10 个源里只有 `v07` 实现了 A；`t03` 和 `t24` 出现了部分变化，但不是 A 指定的分组；其余 7 个源的 A 输出与 B 相同或接近。
2. **输出强烈偏向“每条事实一句”。** 8/10 源 A/B 逐字相同；`t22`、`fixture-r5`、`v18`、`v14` 等 A 计划要求合并的地方，模型仍然全部拆开。B 计划恰好就是全拆，所以 B 的实现率（6/10）高于 A（1/10）。
3. **不能把 B 的 6/10 当成“读了 B 计划”。** B 在所有源上都是同一个“全拆”形状；一个固定的“每条事实一句”策略就能通过 B，而不需要读计划。A 的失败才是这轮的关键：模型没有在 A 和 B 之间做出条件切换。
4. **dev 从未出现成对成功。** 12 个 epoch 的 dev 成对成功都是 0/6，选中的 epoch 9 只是全零里 loss 最低。固定留出的 0/10 不是“选点没选好”能解释的；在这个配置下没有找到能同时执行两份计划的检查点。
5. **停止原因这次是准确的。** 20 条留出输出全部 EOS，22–52 token，没有触顶；不存在“截断导致失败”的解释。

## 3. 能不能说“计划不能控制成句”？

不能。这轮只说明：**在这个材料、这个 77M 基座、这套 120 次更新配置下，模型没有表现出按计划切换组织方式的能力。** 不能外推到所有计划接口，也不能外推到更大的模型或不同的材料。

材料本身还有一个限制要写清楚：B 在所有源上都是“全拆”，是一个统一形状；这让 B 可以被固定策略通过，无法区分“模型读了 B”与“模型默认全拆”。A 的失败不受这个限制影响，但如果要继续，下一轮应让两份计划的组织方式都随源变化，而不是一份原分组、一份统一全拆。
