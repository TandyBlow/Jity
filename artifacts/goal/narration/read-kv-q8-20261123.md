# KV 缓存量化与浏览器内存（2026-11-23）

## 改动

- wllama 引擎支持 `cache_type_k` / `cache_type_v`（f32/f16/q8_0/q4_*），页面为语义 0.6B 打开 q8_0，叙事 1.7B 保持 f16。
- 12,288 上下文的语义 KV：f16 约 1.38 GB → q8_0 约 0.69 GB；叙事 4,096 f16 约 0.46 GB 不变。浏览器内 KV 合计约少 0.7 GB。
- KV 账：Qwen3-0.6B/1.7B 同为 28 层、8 个 KV heads、head_dim 128；每 token ≈ 2×28×8×128×2 B ≈ 112 KB。12,288 tokens × 112 KB ≈ 1.38 GB（f16），q8_0 减半约 0.69 GB；叙事 4,096 × 112 KB ≈ 0.46 GB。
- 提示长度实测：语义最大 1,965 tokens（近期）/ 6,674（20 输入旧记录），叙事最大 488；上下文未缩，避免 20 输入套件的大结算提示被截断。
