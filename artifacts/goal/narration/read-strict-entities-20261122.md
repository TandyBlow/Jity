# 未登记实体校验：首轮结果（2026-11-22，run43）

## 条件

- `strictKnownEntities` 默认开启；`schedHandback=player`、base 1.7B、skip；s05/s06 复跑 3 次。

## 结果

| 运行 | s06 结算门 | 说明 |
|---|---|---|
| a | 干净 | 未登记名没有进入事实 |
| b | 干净 | 同上 |
| c | 命中 | 事实写成「路明非的红色电台被塞进腰间」——没有点名阿豹，是一条自造的 completed 事实 |

- 命中率从基线 4/5 降到 **1/3**；3 次里没有出现「点中止」，模型都在反馈后避开了点名。
- 交还时间 32.1–46.9 s（早交还臂）。

## 边界

- 校验只覆盖「事实文本点名未登记实体」；不点名、但自造完成的（「电台被塞进腰间」）仍会通过。
- 要把这一类也拦住，需要校验「合法失败回合不得有任何 completed 事实」——那是场景级规则，不能作为通用结算规则（正常回合的完成事实是合法的）。更通用的做法是让 actions 层拒绝未知目标，或继续 D-022 的模型路线。
- 叙事层仍可能写未登记实体（run43-c 的正文写了「阿豹接过电台」）；正文门单独负责，不在此校验内。

## 结论

程序级校验把最直接的「点名未登记实体还判成功」压住了，但不是零硬错；D-022 仍未关闭。
