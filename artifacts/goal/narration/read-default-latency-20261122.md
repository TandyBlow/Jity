# 默认路径的真实等待：G8 20 输入（2026-11-22）

从 `artifacts/goal/acceptance/summary.json` 的 20 个输入直接统计（默认调度、无评估臂）：

| 指标 | 数值 |
|---|---|
| 提交→再次可行动（turnWaitMs） | 最小 163.5 s、中位 295.3 s、最大 297.8 s |
| ≤60 s | **0 / 20** |
| >120 s | **20 / 20** |
| >180 s | 19 / 20 |
| 首段可读 | 1.3–39.7 s，20/20 ≤60 s |

## 含义

1. 默认路径下玩家每次行动要等 **2.7–5 分钟**，20 个真实输入无一例外——与「60 秒都很勉强」的用户口径正面冲突。
2. 验收的 60 秒门只测「首段可读」（1.3–39.7 s，全过），完全没测玩家真正的等待；这是验收协议的盲点，不是模型慢一点点的问题。
3. 早交还评估臂 15/15 个回合 35.3–53.5 s；要满足 60 秒，产品路径必须切到早交还，并接受或缓解自动链的取舍（D-024）。
4. 该数据也解释了为什么 G8 有 9 个 295 秒时限收尾：回合跑到页面兜底时限才停。
