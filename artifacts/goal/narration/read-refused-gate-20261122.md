# 被拒动作正文门：unknown_entity_claim（2026-11-22）

## 缺口

run40-e：结算把「递电台给阿豹」判成 `blocked`，正文却写「阿豹接住后转交给了裁判」。旧的正文检查器只认识别带/门/回声/占位/注记五类，这一回合 0 命中。

## 规则

- 从玩家输入里取「给/向/让/跟 + 2–3 字」作为引入的实体名（如「给阿豹」→ 阿豹）。
- 与叙事提示里的已知名单（`（id=`、`名字：`、`让X做的事`、`屋里有X的`）比对；已知的不算。
- 若正文里出现该名字、且所在句子没有 `没有/未能/未被/被拒/拒绝/无法` 的否认措辞，报 `unknown_entity_claim` 并给出原句。
- 排除 `和/与/对` 引导：实测会把「和胸袋」误当人名。
