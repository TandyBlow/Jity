## 一、三个输出臂

| 臂 | 生成方式 | 本轮用途 |
| --- | --- | --- |
| template | `renderCommittedNarration`：每条事实取第一短句逐条拼接 | 页面现有兜底 |
| mechanical | 同一事实的第二短句变体（可换序）——**今天页面判分门的接受上限**；测试断言每条仍通过旧 `checkFactNarration` | 机械拼接天花板 |
| natural | 模型按结构化事实自由成句；失败一次带违规反馈重生，再失败落回模板 | 本批评测对象 |

三臂对同一份 `committed-narration` 事实判分；模板臂另受两个已知缺口约束：
**它从不写时间推进**，**空增量点输出空串**（本轮如实统计，未当作事实错误）。

## 二、判分器（交付一）

`narration-alignment.ts`：句/分句级事实对齐，不是词表匹配。

- **必述**：每个事实须在有该角色名的分句（可跨一个逗号，遇其他角色名即停）中被断言；
- **硬违规**：人物互换、方向反转、数值错误、时长错误、无事实的站位声明、
  无事实的移动声明、无事实的任务达成、无事实的事件动词、空正文；
- **软提示**：既未绑定事实也未构成矛盾的句子记为 `unverified`，只作人工复核
  提示——**词表外表达不判捏造**（`narration-split-experiment-design.md` §3）；
- 重复率：与上一点文本的字符 bigram 最大重叠；时间覆盖单独统计。

判分器自测（`narration-alignment.test.ts`，22 项）逐类给红例：

| 反例 | 期望 | 实测 |
| --- | --- | --- |
| 人物互换（`主角从走廊来到大厅` 用于学生A 的事实） | `actor_swap` | 通过 |
| 方向反转（`从大厅走到走廊`） | `direction_reversed` | 通过 |
| 数值错误（`从10升到13`） | `wrong_number` | 通过 |
| 时长错误（2 秒点写成 `两分钟`） | `wrong_time` | 通过 |
| 未完成任务却说完成 | `task_claimed_without_fact` | 通过 |
| 无事实的站位（`学生A位于走廊`） | `state_claim_without_fact` | 通过 |
| 无事实的移动（被拒行动写成 `走到了门厅`） | `movement_without_fact` | 通过 |
| 新增事件（`他推开门冲了进去`） | `added_event` | 通过 |
| 正常改写（换语序、换连接词、口语化） | 不判捏造 | `violations=[]` 且 `ok=true` |
| 模板臂 / 机械臂（非空样本） | 通过 | 7/7 |

校准中修掉的三处误判（都有回归测试）：`走廊` 自带 `走`，动词检测前必须先遮盖地点名；
`四周` 里的 `四` 不是四分钟；`「帮主角熟悉校园」` 里的 `主角` 是冻结原文而非句子主语。

## 六、结论：哪些能放宽、哪些仍须模板

**可以放宽（判分器已能兜住，模型首稿即被采纳）**

- 位置与移动的措辞：`走到 / 走向 / 来到`、`在大厅 / 位于大厅`、把两句并成一句；
- 多人物同点：允许一句里两个角色的动作各自绑定（按分句归属，不按整句）；
- 数值表达：`从10变为12 / 从10升到12 / 提升至12`；
- 语序与连接词：把「事实列表」改写成一句连贯叙述。

**仍须模板约束（本轮 7/10 的上限来自这里）**

- **任务达成必须保留目标原文**：模型会改写成「取回柜子里的东西」「取出了一件物品」，
  丢掉「完成」语义或引文；建议把任务目标作为不可改写的引用片段，模型只负责前后文。
- **时间推进**：模型倾向写「时间推进：1分钟」这种提示词回声，或干脆省略；建议时间句
  由模板生成（模板现在不写时间是已知缺口），模型不承担时长措辞。
- **空增量 / 拒绝行动点**：模板输出空串，模型只会写「时间推进。」；这两类应由
  「时间 + 现状」的固定句式兜底，而不是让模型自由发挥——它的自由发挥正是本轮
  两例站位/事件捏造。
- **额外站位/事件**：即使重生一次也可能重复（`nv-cont-2` 两稿都多写学生A位置），
  因此这两类样本的重生预算不宜超过一次，直接落回模板更稳。

## 七、边界

- 单模型（Qwen3-0.6B Q4_K_M）、单设备、10 个冻结样本、固定世界（T01 school 语义），
  不是统计结论；temperature 0 + seed 42 保证可复跑，但样本外行为未测。
- 判分器只做**确定性事实对齐**：语义捏造（如「正在完成作业」这类无事实的动作描写）
  仍记为 `unverified` 交人工复核，不被自动定罪。
- 本批**不改页面接线**：`checkFactNarration` 仍是页面唯一的放行门，`rule-session`
  行为未动；是否接入、接入哪种组合，待本结论评审后另行决定。
- A3-2、契约与恢复链保持冻结范围，本批未触碰。

## 九、复核改判（2026-10-28，评审轮）

复核复算了 `run.json` 的逐样本记录（脚本复算，不手算），三处结论需要改判，
判分器本身有四个缺陷。修复与放宽已随 `4e8b211`（模板）、`0d25ea3`（判分器）、

### 9.1 三个数字

**「7/10 = 7/10」不是同量比较。** 模板/机械的 3 个失败全是空点输出空串；
自然的 3 个失败全是事实丢失。按「有事实的 7 个点」分账：

| 臂 | 有事实 7 点 | 空点 3 点 |
| --- | ---: | ---: |
| template / mechanical | **7/7** | 0/3（空串） |
| natural | **4/7** | 3/3（final 全是 `时间推进。`/`时间推进：5 分钟。`） |

自然臂在「有内容」的点上没有一个反超现有门；唯一增量是空点从空串变成
`时间推进。`——无时长、且是提示词回声（8/10 样本至少一次尝试写出回声）。

**「自然补上了时间」不成立。** 通过稿里的时间句全是 `时间推进：N分钟` 形态的
提示词回声，0 条自然成句。把时间当硬要求（`requireTime=true`，5 条人工参照
全过）时，自然从 7/10 掉到 **2/10**（仅 `nv-multi-1`、`nv-multi-opposite-1`）。

**时间覆盖应为 5/10，不是 4/10。** `nv-cont-3` 第二稿 `时间推进：5 分钟。` 被
判 `timeExpressed=false`——`durationsIn` 的正则不允许数字与单位之间有空格。
按修复后的口径复算：5/10。

### 9.2 判分器四缺陷（全部已修，含回归）

1. **零位置事实的点上 `state_claim_without_fact` 完全失效（最严重）**：
   `:338` 的 `positions.length > 0` 短路，三个空点上任何站位声明都放行
   （`主角在门厅。`→ok）。修复后无事实背书的站位一律违规。
2. **日常中文被硬判时长错误**：`UNIT_WORDS.minute` 含裸 `分`，`十分健谈`
   →`10 minute`；`第二天` →`2 day`。修复：裸 `分` 出清单；`第N+单位` 序数
   遮盖（序数是时间位置不是时长）；人格冻结文本内两字以内口语插入
   （变得「十分」健谈）仍绑定同一变化。
3. **汉字数值错误不查**：`wrong_number` 只扫阿拉伯数字，`从十升到十三`
   →ok。修复：`numbersIn` 在值槽位（从/到/为/是/至之后）读汉字 1–99，
   序数与时长先遮盖（`三心二意` 类成语不进检查）。
4. **「额外站位/事件落回模板」缺一条落点**：空点上是缺陷 1 的影子，修复 1
   即闭合。另补一条正向检查：at 事实的角色本点声明移动=捏造
   （`movement_without_fact`）——站位绑定合法化 `学生A已经在大厅里等着了`
   之后，原来的 swap 签名不再能撞见这类句子。

放宽清单按评审意见两步落地：`走到/走向/来到`（已有）、`在/位于` 到达站位
绑定移动事实（新增）、多人同句按分句归属（已有，回归钉住）、
`从10变为12/提升至12`（已有）、语序与连接词（已有）。**仍由模板持有**：
任务目标原文＋完成语义、时间句（模板现已写时间）、空点（固定句式）。

留出集（`d521cff`，六个 `hv-*`，换角色换地点）首跑即抓到修复自身的一处
误杀：`精神值一路` 的「一」落在值槽位被当成数值 1——「值」已从槽位集合移除。
