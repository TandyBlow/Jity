# D03 R3：2–3 人关系与表达变化

日期：2026-11-10。用户授权继续下一轮，保持总共2–3人（含行动者），增加表达变化和关系难度。

## 范围与标签边界

新增24个场景机制组，分为归属/借用、指代、条件/否定、传播/隔离四类，各6组。每组两个事实或动作对照，每个对照三种人工编写式助手改写，共144实例。完整名册与事实进入模型，保留已行动目标。

归属物品遭改变，主人受影响；借用者正在持有/使用时也受影响。已完成赠送后的原主人不自动算目标。指代依据本场景明确关系解析，不凭名字或候选顺序。已知条件不满足且源行动明确规定不执行时为空；不得根据未知骰点或未来失败抹去本应发现的威胁。传播/隔离题针对环境路径，不把“直接攻击可能被挡住”标成无目标。标签全部为助手草稿，未经人审，不是生产语义的最终裁定。

## 冻结与分组

各类别内按 `SHA256('r3:'+机制名)` 排序，前4组训练，第5组开发，第6组测试。对照及全部改写始终同组。新训练96实例、开发24、测试24；再加入R2已冻结训练集96实例复习，仅复用train，绝不使用旧development/test训练。合计训练192实例508候选对，开发/测试各24实例66候选对。新测试仅4个来源机制组，改写不能被当作额外独立来源。

新数据身份见data-manifest.json；来源代码prepare_r3.py。所有人物数量为2或3，包括行动者本身。作用于行动者自己的标签仍为否，程序不事后过滤其预测来修正成绩。没有导入B/C数据。与R2不同，本轮同时改变了难度、数据量、训练起点；不能据分数推导单因素因果。

## 训练

从R2实际选中的第4轮模型继续全参数微调，而非从第8轮或随机新头开始。父模型SHA256：`b4f6dac7db6d74e26bd838a85e5960892eba3e071740b68bae1e5387a997401f`。加载前核验R2记录及文件一致；不修改原模型。分词器同一MacBERT固定底座。

沿用seed42、8epochs、batch8、AdamW lr2e-5、weight decay0.01、clip1、10% warmup线性衰减、训练类频率加权损失，FP32/MPS、CPU2线程。本轮512优化步。输入上限512tokens，超限拒绝，不截断。

只用新开发集选择checkpoint与阈值：0.05至0.95，步长0.05；依次最大化集合命中、最小化漏选、误选、接近0.5，跨轮并列保留较早轮。固定8轮，测试不能用于续训、调参、选择或改标签。

## 最终评测

冻结选择、保存重载后，对新测试评一次；报告整体、人数、类别、非空、空集、组级6变体全部正确、各候选分数以及完整批次延迟。随后对R2旧测试作一次回归（已曝光资料，不称独立测试），另加载不变父模型以其原阈值0.5对相同新测试评一次，作同题起点对照。这些结果都在训练完成后产生，不能回流模型选择。
