# 战役记忆与一致性

## 入口与兼容

Jity 只支持战役生成。`POST /sessions` 不传 `campaign_filename` 时加载
`default_campaign.json`；显式传入 null、空字符串或路径穿越文件名返回 422。
文件不存在返回 404，且不会先创建空会话。旧自由会话和时间线仍可读取，
生成返回 422；首页不会自动继续旧自由会话，会创建默认战役。

## 提交与恢复

每个最终回合（包括固定开场和本地 Examiner 拒绝）先执行物品状态校验，
再把最终叙事、结构化后果、摘要缓冲区和 `version/pending` 一起保存到
`story_turns.state_json` 与当前会话。结局替换在记忆采集之前完成。

后台维护只操作独立副本，启动时捕获当前分支、当前幕的对话。
完成后通过节点 ID 和记忆版本比较写回，只更新记忆字段；
恢复分支或切换存档会取消旧任务，迟到结果不能写入另一个活动节点。
下一回合先等待本会话的维护任务。重启后的 pending 快照会在构建下一条
提示词前重试维护；失败保留输入，生成仍可继续。因此快速连点下一回合时
可能等待尚未完成的摘要请求。

原始缓冲和低层摘要只有在上层摘要成功后才被消费。L2/L3 可独立重试，
提供方标记 `finish_reason=length` 的截断响应在 JSON 修复前直接判为失败，
保留原始输入；短预算 DeepSeek Flash/Pro 辅助调用显式使用非思考模式，
避免推理占尽选项/摘要的输出预算。显式 reasoner 不被改写。
L3 达到阈值后再次压缩。摘要不再写入无分支隔离的全局知识库。
跨幕只重置场景 NPC、近期事件及场景提示，保留长期摘要、待摘要输入、物品账本和显式别名。
旧快照不需要 SQL 迁移；旧遗忘轮次载入时换算成实际游戏回合。

## 物品与检索

SCORE 同时处理 `items_gained/items_lost` 和
`memory_updates.items_upserted/items_removed`，同回合删除优先。
被拒绝的获得事件从输出结构中移除，不会写入背包；Director 使用当前真实状态。
找回和修复分别使用 `transition: recovered`、`transition: repaired`，
Narrator 必须在叙事中说明。名称统一全半角、空白与大小写；仅通过显式
`aliases` 合并同物异名，不推测语义相似名称。该规则校验结构化状态，
不是对任意自然语言叙事的完整事实审查；摘要输入另带权威物品状态。

共享别名拒绝歧义解析，规范名称优先，屏蔽物品名时保留尾随动作的检定触发。
已消耗身份不能重新获得或修复；损毁身份需要显式修复。固定开场的入场物品也需
经过账本核对，不能跨幕复活已消耗的同名物品。背包不再截断到 20 件，接口
`caps.items = null` 表示无固定条数上限；NPC、任务、长期事实仍受原有上限约束。

回合的节点、状态与战役进度同事务提交，成功后才启动维护；失败/取消不提前推进。
回顾与 NPC 关系采用事务内快照和提交后效果，重试不重复增长。
页面的“最终提交的声明”展示经过后端校验/结局替换的字段，不等同于原始模型回答。
存档删除的活动检查和删除在同一 SQLite 写事务内完成，仅移除指定槽 ID。

检索查询包含行动、地点、人物、活跃任务、物品、线索和近期事件。
`MemoryHit` 返回记忆 ID、摘要、层级、总分、语义分、实体命中、重要性、
时近性与命中原因。分数权重分别为语义 0.45、实体 0.30、重要性 0.10、
时近性 0.10、标签 0.05，属于可后续评估调整的工程默认值。
根据来源 ID、摘要内容和跨层回合范围去重。快照恢复后首次检索批量补齐
缺失向量，向量服务不可用时退回实体/关键词排序；正常连续回合复用缓存。

最终截断后的提示词完整包含某条记忆，才会记录这次召回并强化；候选但未注入
的竞争记忆保存抑制系数。维护本身不产生召回记录。分数计算避免指数溢出、
同回合零分母与重复强化，召回历史最多保留 64 个回合。物品变化、任务/事实更新、
NPC 死亡及承诺/线索等关键回合的摘要受到保护，并在上层摘要中继承保护。
命中明细存入 `model_outputs.retrieved_chunks_json`，类型为 `narrative_memory`。

## 验证

`backend/tests/test_memory_consistency.py` 覆盖摘要失败重试、独立晋级、
恢复后向量重建、跨层去重、真实召回强化、抑制持久化、长回合数值稳定、
物品双通道校验与找回、版本比较写回、迟到任务、重启补偿、战役唯一入口，
以及 200 回合的离线层级摘要测试。另保留战役开场、结局、存档和时间线回归。
这些测试使用本地数据库和模拟模型，不代表真实模型下的长剧情质量评估。
