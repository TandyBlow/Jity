# 叙事改写语料 v1（60 条）与预登记判据

日期：2026-11-03。目的：给「把已提交的事实改写成一段叙事」这一个任务准备可训练、
可评判的教材，并在任何模型运行之前冻结判据。

## 文件

| 文件 | 作用 |
| --- | --- |
| `corpus60.jsonl` | 60 条 `{id, split, input, target, facts, origin}`；48 训练 / 6 开发 / 6 测试 |
| `checker.py` | 五层判据；先跑人工参考答案，过不了就改规则，不放宽到模型能过 |
| `checker-v1-freeze.json` | 冻结记录：判据哈希、阈值、校准与篡改结果 |

## 输入从哪来

不是手写的。每一条都是**真管线**产物：

造改动（手写）→ N1 提事实 → N2 按视角选 → N3 分组与称谓授权 → N4.0 装配成文本。

所以输入里出现的每一个词，都能追到权威状态的一处字段；反之，输入里没有的东西，
模型写出来就是新增。

输入包含：

- 这一轮的事实记录（编号｜种类｜内容），种类标签是 `移动/结果/理智/外貌/行为倾向/相对位置/新任务/时间/无变化`
- 场景：地点链（如 `旧灯塔>塔顶`）、整条链与同层兄弟地点的外貌、`同栋=` 名字表、天气与光
- 在场人物：性格、外貌、随身；只列「有选中事实的人」和视角人物，不做全员点名
- 视角：第三人称限知，只写视角人物内心
- 约束行：不写任务标题／数值／具体时长／字段名；不新增未列出的具名人物、物品、地点

## 目标怎么写（风格规格）

1. 字数不设目标，可长可短（本批 87–229 字）
2. 事实不能写错：不换人、不反方向、不漏结果
3. 移动以事实为界：事实说到达某处，就不写回程；用户后来允许写回程，按普通叙事处理
4. 理智不许出现数值，只写可感变化（清醒、心里空了一块、薄了一层）
5. 他人的性情变化只能写成看得见的行为、说话方式，或视角人物的一句猜测，全篇最多点一次
6. 允许自行编造：对话、动作补充、比喻、氛围、感官
7. 不许新增具名的人物／地点／物品
8. 写法四拍：环境铺一层 → 写动作 → 落一处内心（方向与事实一致）→ 停在该停的地方

## 判据（五层）

| 层 | 内容 | 判定 |
| --- | --- | --- |
| 1 | 硬格式：阿拉伯数字、书名号、输入模板残留、截断、过短 | 违规 |
| 2 | 抄输入：只有**事实行**被整行搬进正文才算抄；世界外貌描述可复用 | 违规 |
| 3 | 新增具名实体：人物／地点／子地点／≥3 字物品名必须在输入中出现 | 违规 |
| 4 | 逐条事实：结果内容覆盖 < 0.20、新任务 < 0.80、方向写反、理智写成数值、把他人性情写成确知内心 | 违规或必述缺失 |
| 5 | 主体归属：句中只有别人加代词、缺主体 | 待人工，不判失败 |

阈值全部取自人工参考答案的实测下界：结果最低 0.20（取 0.20）；外貌最低 0.00、
性情中位 0.00（说明该指标对这两类无效，降为软项）；新任务最低 1.00（取 0.80）。

## 校准与篡改

- 人工参考答案：**60/60 通过**
- 篡改探针：**9/9 抓到**——加数字时长、加书名号、加世界册人名、抄输入行、截断、
  空串、理智写成数值、方向写反、结果整段缺失

## 明确不查的东西（盲区，已写进冻结记录）

1. 删掉结果里的一句细节查不出（其余句仍与原文重合）
2. 把主体换成另一个同样在输入里出现的人，只能报「待人工」——中文代词指代无法在程序中解析
3. 文笔、心理是否可信、比喻是否误导，一律不查

## 来源

改动是手写的（`rich20.py`/`rich30.py` 里的 `CASES`），其中 10 条来自已审的叙事开发稿
（`n4_narrative_dev/corpus.jsonl`）。本目录只存最终语料与判据；生成脚本留在工作区。

| 改动 | v5 结果 | 原因 | v6 处理 |
| --- | --- | --- | --- |
| 只把动作句主语换成韩渡，别处仍点名沈砚 | pass | 主体在别处点过名就降级成提示 | 小句里点了别的角色一律进复核，与“别处点过名”无关 |

| 册外人物只出现一次 | pass | 硬性要求重复两次 | 句首 + 姓氏 + 人常做的动作 + 虚词过滤，一次也算 |
| “近处的灯灭了，远处的灯还亮着” | 判矛盾 | 主语中心词取了“的”后面的“灯”，两盏灯混成一盏 | 中心词保留定语，只认字面相同 |
| “韩渡没有抓住灯杆” | 判否定 | 整句扫否定词，不管是谁被否定 | 逐小句扫，否定必须落在主体所在小句 |
| `score_probes.py` 退出码 | 漏检篡改仍返回 0 | 只检查 `blocking` | 篡改漏检也进 `blocking` |

## 跨行回归集（`regression.py`）

对 140 条参考稿套同样的改动，生成 `regression_set.jsonl`（643 条）。

**口径按分母分开**：错放率只除以错误样本，不被正确样本的数量稀释。

| 指标 | 用户口径（643 条） | 当前（剔除 5 条数据错） |
| --- | --- | --- |
| 错误样本被放行 | 19/223＝8.5% | **18/221＝8.1%** |
| 换主体样本被放行 | 19/56＝33.9% | **18/55＝32.7%** |
| 册外人物 / 删结果 | 0/167 | 0/166 |
| 正确样本被判失败 | 0/420 | **0/417** |
| 正确样本进入复核 | 39/420＝9.3% | **39/417＝9.4%** |
| 全部样本复核率 | 83/643＝12.9% | **83/638＝13.0%** |

差额来自 `n4n-03`：它的移动事实写“从河心”，而世界实体表里没有“河心”。这类行现在不计入任何比率，单独报成**数据错**（5 条），免得把“实体表缺条目”读成“判据抓不到”。

漏掉的 18 条集中在**只含移动事实的行**：这类 9 条里抓到 1 条；含结果/外貌事实的 47 条抓到 36 条。缺的是“谁在场于某地”的绑定。

**结论（收窄）：** **20 条定向样本全部符合预期；跨行回归仍有 18 条错放**（换主体 18/55，集中在纯移动行）。`pass` 的含义是“这些规则没发现问题”，不是“事实已核验”。判据可以当闸门用，不能当核对结论用。

**这批回归集不是干净的留出集：** 第一遍跑出 36 条错放，之后据此改了一处规则（主体全篇未点名时不再要求句内有代词）并修了一处标注错误（删句后仍覆盖大半的样本改标 pass），才得到上表。

## 隔离集（`isolated.py`）

隔离集落地前先改掉三件事：

1. **标签不再由检查器推出来。** 每条自带 `facts` / `input` / `text`，`label` 由人写并标 `labelSource: "human"`；`fail` 的必须写 `wrongFacts`（错在哪个 factId）和 `errorTypes`。校验器见到非 human 标签直接拒绝。上一版 `regression.py` 用双字覆盖率挑“删结果”样本，会漏掉“覆盖率高但关键事实已漏”的情况，这条路不再用。
2. **每个世界带自己的实体表。** `load_world_names(path)` 接受路径，行里的 `world` 字段指向该行的世界，脚本逐行解析。同一段正文，用 `fixtures/world-mini.json` 判是 pass，换成旧世界判是 `new-entity` 失败 —— 测的确实是核对能力，不是实体表缺失。事实引用了实体表里没有的名字时，单独报**数据错**，不计入任何比率。
3. **每组同时有正确稿和错误改写，并支持配对。** `pairId` 把一正一错连起来，校验器要求同组、同世界、标签相反；严格模式下每组至少一对。

运行策略：`--freeze-labels` 先把标签连同样本哈希、判据哈希写进 `<集合名>.labels.json`；`--run` 要求这个文件存在且样本哈希一致。之后**允许重复运行**（复现结果），每次记进 `<集合名>.runs.json`。如果判据哈希变了，这次运行自动标成 `post-tuning`，不能再叫未见测试集。

冒烟样例 `fixtures/isolated-smoke.jsonl` 只有 2 条，证明管线能跑通，不是隔离集。

正式隔离集 v1 的结果见 [`isolated-v1/report.md`](isolated-v1/report.md)：盲测 13/24 放行，改完三处结构错后 2/24 放行、12/24 进复核、误拒 0。

# 判据 v5（2026-11-04，已被 v6 取代）

> 下面这段是 v5 当时的记录，文件数和数字都停在 v5。当前状态看最上面的 v6 一节。

## 为什么改

v4 的结论是「140 条人工稿全过 + 14 条篡改全抓」，但它证明不了事实核对可靠。用户复跑发现四处语义漏检、两处误判：

| 改动 | v4 实测 | 机制 |
| --- | --- | --- |
| 沈砚的动作改成韩渡 | 通过 | 第 5 层只写 `pending`，`pass` 只看 `V` 和必述缺失 |
| 完成写成“没有完成” | 通过 | 只算结果原文双字覆盖率，“没抓住”里也有“抓住” |
| 加册外新人物“任云川” | 通过 | 第 3 层只遍历世界册里那 66 个名字 |
| “手背冰凉，灯的铁皮发烫” | 判矛盾 | 整句扫冷热词，不看是不是同一物体 |
| “远处的灯灭了，警示灯还亮着” | 判矛盾 | 同上 |

外加 `main()` 写死 `caught == 6`（实际 14 条用例），全抓到也返回退出码 1。

## v5 改了什么

- 判决三档：`fail` / `review` / `pass`。**`review` 不算通过**，并给出原因码。
- 矛盾按小句判，比较谓词前的主语中心词，只有指同一物体才算（“灯”对“警示灯”不算）。
- 否定：整句定位事实后看否定词紧邻 3 字是否落在结果动宾上。
- 册外新人物：姓氏表 + 2–3 字 + 重复至少两次 + 跟人常做的动作。
- 主体绑定：主体全篇没点名、却点名了别的角色 → `review`；别处点过名的承前省主语 → 只记提示。
- 结果收尾：结果末尾两个实词双字全篇找不到 → `review`。
- 退出码改成 `caught != total` 才失败。

## 仍然查不出的（写进冻结记录）

1. 谁做的这件事：小句主语不是事实主体时只进 `review`，不判违规。
2. 结果只做了一半：词面覆盖对不上才进 `review`，可能漏。
3. 文笔、心理是否可信、比喻是否误导：不查。

## 这套样本自己的局限

- 样本是从 r01 一条参考稿改出来的，覆盖面靠类别补（换人、否定、漏结果、反向、册外名字、冷热并存、远近两盏灯、代词、段序、对话），不是独立采集的自然输出。
- **改规则之后有三条样本的期望值从 `fail` 降到了 `review`**：p01 换主体、p05 漏最后一步、p09 全篇只用代词。规则确实只能判到“看不出来”，所以调低的是期望，不是判据 —— 这三类仍然是漏检，只是现在不会被记成通过。
- 判分脚本和判据是同一个人写的，样本里没有“设计规则时没见过的世界”。第 2 步的隔离测试组就是补这个缺口。

**结论：** 判据现在可以当自动闸门用（不放行语义错，也不误伤正确写法），但它只能确认 127/140 那种量级的“可核性”。整段叙事的忠实度不能只靠它，需要第 2、3 步（隔离测试组 + 三种任务形状）配合。
