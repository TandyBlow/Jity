## 2. u240 适用性（先定规则，再看输出）

| N1 事实 | 适用 | 理由 |
|---|---|---|
| `moved` | 是 | 主体、起点、终点都是状态里的名字，可直接写事实行 |
| `task_achieved` | 否 | u240 的输入要“结果句”；N1 只有 goal+status，没有 resultText；补写就是造数据 |
| `sanity_changed` | 否 | u240 输入不允许数值；N1 只有 9→8 这类数字，没有描述词 |
| 其他 | 否 | 不在 u240 的四类事实契约内 |

因此 72 个可达点里，真正能调用 u240 的只有 **moved**（53 次出现，2 个不同签名）。

## 3. 冒烟运行（2 次 u240 调用）

运行目录：`artifacts/fact-wording/real-state-smoke/20261108T180059-realstate/`。

点 1：`b3-debug-action-db/world.db` `point_7`，version 1，前驱 `root_3`，`entityDeltas` 为 `person_c.positionSet=hall`。
输入（状态推导，无补写）：

```

地点可见=

视角=周宁

判定：**失败（新增动作）**——“抬头看了看门厅”不在事实/场景里；“脚下”也是加的位置细节。

点 2：`world-chain-full-1793200688255/world.db` `point_19`，version 3，前驱 `point_13`；目标走廊，可见物品“盒子”。

```
地点=走廊

场景=上午

事实=周宁｜移动｜门厅→走廊
