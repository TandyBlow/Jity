# 输出预算对照：128 → 384（real-batch-v2）

日期：2026-11-08。分支 `exp/c-round-composition`。

**一句话结论：把输出上限从 128 提到 384 后，截断从 10/10 降到 2/10，硬门通过仍是 0/10。**即：预算提高显著减少截断，当前硬门通过率仍为零。

## 1. 本批只改了一个变量

| 项目 | v1 | v2 | 说明 |
| --- | --- | --- | --- |
| 样本 | 10 | **同一份文件**（字节相同） | `fixtures/batch-v1-cases.json`，v2 登记里记了它的哈希 |
| 模型 | `qwen2.5:7b` / `845dbda0…` | 同一个 digest | 登记时重新读取 ollama tag，digest 不同就拒绝登记 |
| prompt | N4.0 结构化记录 | 相同 | 直接复用同一份输入点生成的文本 |
| 判定器 | `judge_v3`（n5-v3） | 冻结不变 | 看过 v1 结果后没有扩词表、没有改帧 |
| 重试/回退 | 2 次 + 模板 | 相同 | 第 2 次仍带上一轮问题 |
| **输出上限** | `num_predict=128` | **`num_predict=384`** | 唯一变化 |

预登记文件：`fixtures/batch-v2.json`（写在任何 v2 调用之前）。主结果是**首次调用**，重试单独列；截断样本留在分母里。

## 2. 开跑前的三处补正

| 补正 | 做法 |
| --- | --- |
| 触发线按预登记原文 | 预登记写「失败 ≥3/10」，v1 代码写成 `<7`；v2 实现为 `hardGateFailSamples >= 3`（失败样本数），端口失败按**调用次数** `>= 2`。边界测试 `test_tripwire_v2.py`：2 不触发 / 3 触发、1 次端口不触发 / 2 次触发、n5Pass 0–10 全部对齐 `>=3` 规则。 |
| 收紧报告措辞 | v1 报告改为「整段末尾截断」；提示词范围 164–303；撤回「仿佛静止/过去了一会儿」的矛盾判定（见 `fixtures/errata-v1.json` E2–E4）。 |
| D4 分类 | 收紧为**只计专名**：`铁环`/`广场` 与「木门/楼梯」同属普通名词，归 N6 的「新增物件/地点描写」；v1 的 5 条标注按新口径为 0 条专名新增（E5）。v2 的 D4 从这批起按新规则执行。 |

## 3. 结果（主结果 = 首次调用）

| 指标 | v1（128） | **v2（384）** |
| --- | --- | --- |
| 首次调用正常结束（`done_reason=stop`） | 0/10 | **8/10** |
| 首次调用触顶（`length`） | 10/10 | **2/10**（`rb-two-actors-move`、`rb-time-only`） |
| 首次调用硬门通过 | 0/10 | **0/10** |
| 重试后硬门通过 | 0/10 | 0/10 |
| N6 通过 | 0/10 | 0/10 |
| 输出 tokens（首次调用） | 全部 128 | 215–384 |
| 提示词 tokens | 164–303 | 164–239 |
| 单次调用耗时 | 2.8–3.2 s | 均值 7.4 s，中位 6.8 s，最大 18.4 s |
| 回退产出 | 9 次 | 9 次（`rb-subtask` 仍无模板帧） |
| 触发线 | 触发 | 触发（失败样本 10 ≥ 3） |

**384 是否足够？** 对 8/10 足够（自然结束），对 2/10 不够（仍触顶）。所以「把预算提高」能解决「写不完」，但不能解决「过不了门」。

## 4. 现在失败在哪里（按首次调用逐条）

| 样本 | 硬门问题 | 观察 |
| --- | --- | --- |
| rb-move-outcome | 移动、结果都未覆盖；残留人名 | 整段完整；正文始终在钟楼内部，从没写「从管线镇来到钟楼」；结果被改写成「将铜铃挂回原位」 |
| rb-time-vague | 移动、结果、时间都未覆盖 | 时间只作为景物（「夕阳的余晖」）；没有时长也没有模糊表达 |
| rb-inner-change | 外貌、个性、理智都未覆盖 | 「话少了许多」出现在正文里，但没有帧，不可核对；理智只写成「理智很重要」 |
| rb-two-actors-move | 两人移动未覆盖；**触顶** | 截断；自撰对话与意图 |
| rb-same-name | 三人移动未覆盖 | **G4 触发且满足**（两个「管线乙」分别出现）；但三人被写成在楼下站着，没有移动 |
| rb-subtask | 移动、新任务未覆盖 | 找梯子被写成完整的寻找/拼接/固定过程，与「接到新任务」不是同一件事 |
| rb-sanity-only | 个性、理智未覆盖 | **D4 唯一真专名：老李**（新增人物 + 对话） |
| rb-time-only | `no_change` 未覆盖；**触顶** | 截断；自撰任务（检查地下管道）、探测器、堵塞 |
| rb-conflict-two-actors | 两个结果未覆盖 | **把输入小节标签抄进正文**（「场景：」「行动与心理：」「可见动作：」）；第二个结果只在窗口外出现 |
| rb-move-other-appearance | 移动未覆盖 | **抄写并篡改记录行**：`f0｜移动｜钟面→钟楼边缘`、`f0｜移动｜钟楼边缘→钟楼内部`，与真实事实（管线镇→钟楼）不符 |

三类问题分开记：

1. **形态**（主因）：模型把结构化记录当素材，用自己的叙述框架（推门、环视、心路）替代事实陈述；「从A来到B」「完成结果」「外貌变了」这些帧很少被直接满足。
2. **格式回显**：3 个样本把小节标签或记录行抄进正文，其中 1 个还改写了记录里的起止地点。
3. **截断**：只剩 2 个样本，仍留在分母里，没有剔除。

## 5. D4 与 N6（v2）

- D4（专名规则）：10/10 已检查，**1 条专名**（`rb-sanity-only` 的「老李」，新增人物并与其对话），其余为 0。`钟架`、`木梯`、`小巷`、`老邻居` 等物件/地点描写按 E5 归 N6，不计入 D4。
- N6：10/10 已执行，**0 pass / 10 fail / 0 undetermined**，理由逐条写在 `fixtures/review-v2.json`。**N6 与 N5 独立**：正则没匹配到的记在 `n5Formal`，不作为 N6 理由；「将铜铃挂回原位」「雨水浸透外袍」「肩膀抵住了钟沿」都算**已传达**，相应样本的失败改由缺失移动、自撰内容或格式回显承担。reviewer 为单一复核者，状态 `pending-independent-review`。
- 绑定尝试：复核只针对**首次调用**（`reviewedAttempt=1`）；重试正文未复核，合并归档里 `qualityPrimary` 是首次质量、`qualityFinal` 全部 `pending`。
- 移动统计的分母是**6 个带移动事实的样本**（rb-move-outcome、rb-time-vague、rb-two-actors-move、rb-same-name、rb-subtask、rb-move-other-appearance），本批 6/6 未传达；其余 4 个样本没有移动事实可写。
- 三处口径更正的记录见 `fixtures/errata-v2.json`（N6 语义独立、尝试绑定、移动分母）。

## 6. 这一批证明了什么、没证明什么

**已证明**
1. 输出上限是 v1 的主要约束：同一组样本、同一模型、同一 prompt，只改 `num_predict`，自然结束率从 0/10 升到 8/10。
2. 384 不足以让全部样本写完（2/10 仍触顶），所以「足够」的答案要按事实类型分别看，不能一概而论。
3. 预算解决后，硬门仍然 0/10，且失败原因可以被逐条定位到形态、回显、截断三类——不是笼统的「模型不行」。
4. 机制层面：预登记、主结果与重试分列、触发线按原文执行、D4/N6 与原始归档分离，全部可用；v1 归档与 `b594c008…` 未动。

**没有证明**
1. 模型能不能在「提示词明确要求输出形态」后满足帧——本批按要求**没有**改形态要求，留待单独对照。
2. POV、他人内心、对话是否应升级为硬门——仍由 N6 记录，未改判定器。
3. 措辞差异（如「过去了一会儿」vs 词表里的「过了一会儿」）是模型问题还是门太窄——判定器冻结，本批不扩词表，需要一次只改一个变量的对照批。
4. 任何质量结论：N6 全 fail，且是单一复核者。

## 7. 建议的下一步（仍需裁决）

1. **输出形态对照批**：只改 N4.0 的要求行（只输出一段、不复述字段行、不写对话、不写他人内心、每句必须落入事实），样本/模型/预算/判定器全部冻结，看硬门通过率变化。这是能把「形态问题」与「能力问题」分开的最小实验。**该批已在 v3 执行**，结论见 `real-batch-v3.md`：形态生效、硬门仍为 0/10。
2. **帧的对照批**：另起一批只放宽「移动」与「结果」两个帧（如允许「走进/抵达」与结果同义转述），必须先预登记并接受旧成绩不可比的代价。
3. **截断**：对 2 个触顶样本单独登记更大预算（如 512）或要求更短输出；不要混进本批数字。
4. 在 1–2 有结果之前，本批只能作为「预算对照」的证据，不能作为质量基线。
