# N5 v4.1：三处反例的修复（v4 结果保留）

日期：2026-11-09。`judge_v4_1.py`（`n5-v4.1`）。**`judge_v4.py` 与 `out/archive-rejudge-v4.json` 未改**，v4.1 的重判另存 `out/archive-rejudge-v4-1.json`；v1–v3 归档依旧只读。

## 1. 修了什么

### A. 结果归属：旁观者不再记到旁观者头上

评审反例：`管线甲站在旁边，看着王五把铜铃挂回了钟楼。`

v4 在整句里找「管线甲」，又只检查它之前有没有旁观动词，所以把王五做的事记成了管线甲的结果。

v4.1 的规则：

1. 主体必须与结果处在**同一个逗号分隔的小句**里；不在同一小句时，若句中出现旁观动词且在「把」之前另有行动者（如「看着王五把」），判 `attribution-other-actor`，直接拒绝。
2. 主体与结果之间只允许连接词（后来/又/于是/随后/终于/才/便…）跨逗号绑定；小句里出现人名字样的（如「王五」）不绑定，送 `needs-semantic-review`。
3. 没有任何旁观动词、但结果小句里没有主体时，仍按 v4 的「结果无主体」送 N6，不算通过。

验证：带逗号、不带逗号、`听见` 三种写法都拒绝；`管线甲站在旁边，王五把…` 送审；正常句仍通过。

### B. 同名识别描述必须修饰对的人

v4 只检查描述在全文出现过，所以「两段把身份写反、但把两个描述都用上」的正文会通过。

v4.1 对每个同名实体的匹配片段取出上下文窗口（匹配起点前 8 字），要求：

- 该实体自己的描述在这个窗口里；
- 另一个实体的描述不在这个窗口里。

验证：正确绑定通过；描述互换、两个描述挤在同一段、完全没有描述，全部 `undetermined`。`rb-same-name` 的世界状态里 `char_pb=急躁`、`char_pc=沉默`，渲染器与判定器现在都从这份状态取描述（来源统一，见 `n4_groups.py` 的 `descriptor()`）。

### C. 否定词只看承载结果的小句

评审反例：前句失败、后句重试成功（逗号连接）。v4 在整句里找否定词，会把成功句误拒。

v4.1 把否定与未实现的扫描范围收窄到**承载结果的那个逗号小句**；引语仍按整句检查（引号可能跨逗号）。验证：

- `管线甲先没挂上，后来把铜铃挂回了钟楼。` → 覆盖（不再误拒）；
- `管线甲并未把…`、`如果…`、`难道…`、`他说「…」` → 仍然拒绝；
- `管线甲犹豫了一下，把铜铃挂回了钟楼。` → 覆盖。
