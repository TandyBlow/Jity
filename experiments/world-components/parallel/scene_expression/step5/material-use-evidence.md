# 增补素材是否被正文使用：逐项证据

日期：2026-11-08。结论先行：**只有 1 个片段能把用词归因到“只在增补头里出现的素材”，而且它落在一句被初审判为 unsupported 的句子里。其余外貌词句都同时存在于三臂共用的事实行，不能单独证明背景素材被采用。**

判定口径：

- “仅增补头”＝该文本只出现在 B（或 C）增加的场景头行，三臂共用的事实行里没有。
- “输出片段”＝30 份初稿里的实际字符串，注明样本与臂。
- 若同一文本已在共用事实行中出现，即使正文照抄，也只能证明模型读到了事实，不能证明它用了背景素材。

## 这说明了什么

1. 外貌类素材与“本轮外貌事实”同文：本批十题里，B 新增的地点/物品外貌正好等于必述事实的原文（`ns-appear-1`、`ns-loc-appear-1`、`ns-multi-1`）。所以正文里的外貌词句**不能**当作“背景素材被采用”的证据；它们首先证明的是模型读到了事实行。
2. 唯一可归因的素材用词是 C 臂的“外向”，出现在一句初审 unsupported 的句子里（`学生B的外向,有些发紧,…`）。它说明 C 的个性素材确实进了正文，但没有带来可读的、合法的句子。
3. “素材被使用”目前只能写成：**C 臂有个性词进入正文一处；B 臂没有任何可归因的增补素材用词。** 这与“素材改善了叙事”是两件事，后者仍无证据。
