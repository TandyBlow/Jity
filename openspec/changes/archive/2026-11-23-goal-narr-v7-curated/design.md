# Design: goal-narr-v7-curated

## 数据与工作流

- 变体：只交换无归属物品、无移动动词的事实；unsettled 去掉主角结算事实。
- 工作流：10 条/批，写作 + 对抗校验；9 批因 502/429/输出超长失败；接受目标多为整份状态复述。
- 过滤：长度 ≤260、无状态清单短语、无时间数字、无主角事实交换；检查器再筛 5 条。
