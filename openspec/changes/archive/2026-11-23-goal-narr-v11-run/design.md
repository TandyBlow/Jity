# Design: goal-narr-v11-run

## 叙述分点

- 每个玩家回合拆两个 point（player group + instant roster）；页面正文是两个 point 叙述的拼接。
- 逐点抓取放在页面 turn record 的 `pointPrompts`，由驱动原样透传，便于把真实 prompt 与训练形状对齐。

## 根因

- run113：point 1 的结算把观察/清点判成「路明非：看懂了规则牌」（0.6B 归因错误）；叙事照写，被误读为叙事填充。
- 同一 NPC 反应在两个 point 各结算一次，正文出现近乎重复的两段。
- run113 s06：结果重试丢掉「阿豹」写「递出了红色电台」，旧门只查名字，放行。

## 修法与结果

- 门加严：按成员动作里的未登记名字，检查该成员未带否定线索的成功 fact；有 blocked 判词则按判词改写，否则拒绝。单测 102。
- run114：5/5 完成；s06 结算改为 blocked，叙事写出交接失败；交还 74.8/37.0/75.1/99.0/65.8 s（1/5 ≤60 s）。
- 检查器：两处误报修正后 run113/run114 与 v11 数据均 0 命中。

## 判定

- 叙事层不再凭空添加未结算的主角动作；剩余阻塞是 0.6B 结算归因、两 point 重复叙述、60 秒回归。交付判定不变（D-026）。
