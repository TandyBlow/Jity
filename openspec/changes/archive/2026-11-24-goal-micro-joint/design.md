# Design: goal-micro-joint

## 切分

- train = `labels-v1..v4`（60/任务），test = `labels-v5`（15/任务）；测试标签全部在训练中出现；v5 含铜哨、医护附楼对抗行。

## 训练

- 共享 MiniRBT + 四头，8 epoch、lr 2e-5、seed 20261124。
- T1 固定文件顺序；T2 每 epoch 行级打乱；T3 打乱且训练输入截断 32。

## 评估

- 自然输入、截断 8/16/32/64/128；截断是下界（可能切掉候选列表），不是重设计。
- position 手写 15 条 ≤32 token 压缩输入（保留事实/当前/候选字段），作为同长度的上界。
- 每任务精确匹配；train 与 test 同报。

## 速度

- T2 fp32 与动态 int8；样本为 512-id 前缀截断到 8/16/32/64/128；1/4 线程；p50/p95。

## 判定

- 若 32 token 下压缩输入准确率接近自然输入，且 T2 在 32 token 的延迟 ≤10 ms，则「32 token 部署」成立。
- 截断曲线只用于显示信息损失，不作为部署配置。
