# Design: goal-micro-reasoning

## 任务

- 每条场景一组事实（转移、阻断、否定、在场），问「钥匙最终在谁手里？」答案为人物名或「无人」。
- 例：路明非把钥匙交给诺诺；诺诺又把钥匙给芬格尔；芬格尔被拦下（没交成）；问最终持有者 → 诺诺。
- 50 条，4–8 个事实，答案唯一；含否定、阻断、代词、复合转移。

## 四臂

1. 纯规则：逐条解析事实，维护持有者（本题规则可解，作为上界/基线）。
2. 单次模型：把全部事实一次给 0.6B，要求答案。
3. 串行协作：逐条事实交给模型判断「这条是否改变持有者」，规则聚合状态（单向，无反馈）。
4. 反馈协作：0.6B 给初始答案；10M 句对打分器逐条核对「该事实支持/反驳当前答案」；规则聚合出矛盾事实；把矛盾事实回喂 0.6B 修正；重复 2–3 轮。

## 指标

- 答案准确率（每轮记录）、调用数、轮数、延迟。
- 关键判定：反馈轮数增加是否带来准确率上升；若无，如实记录。

## 基线说明

- 本题规则可解，规则臂是上界；研究目的是看模型协作能否接近规则，而不是击败规则。
- 0.6B 用产品同款 Q4，10M 用 int8 句对打分器。
