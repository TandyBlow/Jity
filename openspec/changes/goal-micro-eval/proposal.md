# Proposal: goal-micro-eval

## Why

今天的实验都是 Agent 自己写测试集、自己调模型、自己在同一批数据上验收；规则与测试集同源，模型与规则的输入也不对等。复核轮指出：继续零散探针无法区分「模型能力不足」与「任务设计/训练数据/评估方式有问题」。需要一个冻结规则与模型、由独立作者编写、可重复使用的评测集。

## What Changes

- 冻结规则与两个模型（sha256 记录在 `artifacts/goal/micro-eval/protocol.md`）。
- 独立作者写 300 条自然语言游戏行动，覆盖陌生人物/场景、多轮对话、复合行动、隐含意图、上下文指代；每类 ≥30 条。
- 五方案对比：纯规则、10M 模型、规则+模型、0.6B、云端大模型。
- 指标按 tags 分组报告；规则能解决的构造不要求模型赢。
- 本 change 只定协议与 harness 骨架；数据由独立作者提供后才开跑。

## Capabilities

（无；研究评测。）

## Impact

- 不产生产品代码变更；数据作者是外部依赖，未到位前不调模型。
