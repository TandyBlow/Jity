# Design: goal-narr-attribution-data

## 变体生成

- 世界登记表：`data/worlds/dragon-raja-free-day.world.json` 的 characters/items/positions。
- 只交换「动作/观察」类事实的主语；跳过：主角自己的事实、文本含他人归属物品（相机、短枪、短讯机、识别带、护目镜、背心、钥匙、电池、演习枪、弹匣、信号旗、安全绳、饮水杯、饭票夹）的事实、含移动/位置动词（走、进、上、站、停、跑、穿、爬、退、蹲、坐）的事实。
- 新主语只能是在场角色（状态段「X也在」+ 主角）；目标句按同一主语替换。
- 生成 23 条，扩展检查器 0 命中。

## 训练与结果

- 107 行、5 epochs（从 base 重训），GGUF Q4_K_M `b4b143c7…`。
- run98：10/10 ≤60 s（27.1–55.6 s），正文 78–137 字，重复句消失。
- 硬错 3/9：t3/t9 规则阅读归因、t8 未结算移动 + 凭空放绳 + 心理活动；t5 轻判。
- 检查器 3 命中：t8 `place_claim` 为真；t4 `unknown_entity_claim`、t8 `band_claim` 为既有 knownNames/band 误报。

## 判定

- 归因扩充有效（6/9 → 3/9），未到零；v5 作为评估臂保留，默认不变。
- 下一轮只针对「规则阅读归因」和「未结算移动」两个形状造变体，避免评测集泄漏。
