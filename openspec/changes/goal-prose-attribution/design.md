# Design: goal-prose-attribution

## place_claim

- 从提示取 `路明非现在在([^，。；\n]+)`；按地点族归并（钟楼/门厅/二层平台/顶层旗台为一族；西侧服务巷/检修口为一族）。
- 正文按 `。！？；\n` 切句；若某句同时含「路明非」、一个异族地点名和移动动词（走到/上到/进了/站在/停在/穿过/跑到/赶到/爬上等），记 `place_claim`，并带 `committed`。
- 同族不报，避免「在钟楼里上二层平台」误伤。

## item_owner_claim

- 提示按 `。\n` 切句（状态描述常用分号分隔，按分号切会丢掉主人名）；若含物品的句子点名了主人、且没有句子把同一物品给主角，则视为他人所有。
- 正文若让「路明非」使用该物品（短枪/枪口、短讯机/短讯、相机、器材笼钥匙、演习枪），且同句没有主人名，记 `item_owner_claim`。
- 只覆盖 5 个有明确归属的物品；识别带仍由旧 `band_claim` 负责。
