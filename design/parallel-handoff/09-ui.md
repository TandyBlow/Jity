# 09-ui 交接：可接线的阅读、历史、状态与操作组件

## 1. 问题

`/world-local` 页面把正文、状态、历史、保存反馈和操作按钮都写在页面里，主 agent 正在改这个页面，不能由 UI 线抢改。结果是没有一组稳定的展示组件：正文无法区分流式/已接受/失败，历史没有缓存缺失提示，状态和历史挤在一起，暂停/取消/同步未接通时也没有明确的禁用原因。

本线交付一组只读展示组件和回调 props。它们不 fetch、不驱动模型、不读写 localStorage，也不持有第二份 `WorldState`；页面负责把已有 session 的状态传进来，组件负责显示并请求页面执行动作。

## 2. 交付文件

  - `narration-view.tsx`、`history-panel.tsx`、`world-status-panel.tsx`、`game-controls.tsx`、`progress-status.tsx`、`world-local-layout.tsx`

- `frontend/src/app/world-local-components-preview/` — 仅供组件验收的 noindex 预览页；不加载模型、不读写真实存档、提交不会生成正文。
- `frontend/scripts/parallel-ui/check-preview.mjs` — 用本机 Edge 检查预览页的交互、键盘路径、禁用原因和移动端横向溢出。

## 3. 导出 API

从 `@/components/world-local` 导入。核心 props：

```ts
// 正文：真实 streaming / accepted / failed 状态
<NarrationView
  state={{ phase, text, pointId?, elapsedMs?, failureReason?, alignmentNote?, previousText? }}
  onRegenerate?={() => void}
  regenerateDisabledReason?: string | null
/>

// 历史：只列已提交时间点；status 为 null 时显示“正文状态未读取”
<HistoryPanel
  entries={{ pointId, sequence, kind, timeLabel?, command?, status }[]}
  headPointId? selectedPointId?
  onSelect?={(pointId) => void}
  onRegenerate?={(pointId) => void}
  regenerateDisabledReason?
/>

// 状态：页面用 worldStatusFromState(await session.state()) 生成
<WorldStatusPanel status={worldStatusFromState(state)} pendingTaskLimit?={6} />

// 操作：未传回调或状态不允许时按钮禁用并显示原因
<GameControls
  value onChange onSubmit={(text) => void}
  phase? busy? paused?
  onPause? onResume? onCancel?
  submitDisabledReason? pauseDisabledReason? resumeDisabledReason? cancelDisabledReason?
/>

// 进度：sync 为 null 时明确显示“同步尚未接线”
<ProgressStatus
  online save={{ state, savedAtLabel?, detail?, error?, onRetry?, retryDisabledReason? }}
  sync={null | { state, lastSyncedAtLabel?, error?, onSync?, syncDisabledReason? }}
  forks={[{ snapshotId, parentSnapshotIds, revision, savedAtLabel, summary? }]}
  activeForkId? onChooseFork? chooseForkDisabledReason?
/>

// 可组合页面骨架：主列正文+操作，侧栏状态+历史+进度
<WorldLocalLayout
  title subtitle? meta? banner?
  narration controls status history? progress? footer?
/>
```

`phase` 使用页面已有的 `loading | ready | thinking | streaming | paused | error`。

纯函数（便于页面转换已有数据）：

- `worldStatusFromState(state: WorldState): WorldStatusView` — 只读；
- `historyEntriesFromPoints(points, { narrationStatusById, commandByAdvanceId })` — 新→旧排序，不猜缓存状态；
- `narrationStreaming` / `narrationAccepted` / `narrationFailed` — 生成 `NarrationState`；
- `splitNarration`、`formatWorldTime`、`narrationStatusLabel`、`historyKindLabel`；
- `controlAvailability`、`isSubmitShortcut`（测试用）。

## 4. page.tsx 接线片段（主 agent 执行）

> 只读示例，未改 `frontend/src/app/world-local/page.tsx`。下面的片段要合入页面自己的 state/refresh/submit 流程。

```tsx
import { readAllPoints } from '@/lib/world-engine/runtime/world-reads';
import {
  GameControls, HistoryPanel, NarrationView, ProgressStatus, WorldLocalLayout, WorldStatusPanel,
  historyEntriesFromPoints, narrationAccepted, narrationFailed, narrationStreaming, worldStatusFromState,
  type HistoryEntry, type NarrationState, type WorldStatusView,
} from '@/components/world-local';

const [narration, setNarration] = useState<NarrationState>({ phase: 'idle', text: '' });
const lastAccepted = useRef<NarrationState | null>(null);
const [statusView, setStatusView] = useState<WorldStatusView | null>(null);
const [entries, setEntries] = useState<HistoryEntry[]>([]);
const [selectedPoint, setSelectedPoint] = useState<string | null>(null);
const [paused, setPaused] = useState(false);

// 模型回调：流式与 accepted 分开；校验失败仍保留正文，只加提示
const model = new LocalGameModel(semantic, {
  // ...
  onNarrationProgress: (progress) => {
    setNarration(narrationStreaming(progress.pointId, progress.raw, progress.elapsedMs));
  },
  onNarrationComplete: (progress) => {
    const next = narrationAccepted(progress.pointId, progress.raw, {
      elapsedMs: progress.completion.wallMs,
    });
    lastAccepted.current = next;
    setNarration(next);
  },
  onTask: (task, _key, detail) => {
    if (task !== 'narration' || !detail.fallback) return;
    // onNarrationComplete 先触发、onTask 后触发，所以只给已接受状态补提示
    setNarration((current) => current.phase === 'accepted'
      ? { ...current, alignmentNote: detail.error ?? '事实校验未通过' }
      : current);
  },
});

// refresh：状态、head 正文、历史时间点
const state = await session.state();
setStatusView(worldStatusFromState(state));
const context = await session.transport.execute('get_context', {}, { worldId: session.worldId });
setPaused(context.control.paused);

const head = await session.transport.execute('narration_get', {}, { worldId: session.worldId });
if (head.data.narrationStatus === 'ready' && head.data.text) {
  const restored = narrationAccepted(head.data.pointId, head.data.text);
  lastAccepted.current = restored;
  setNarration(restored);
}

const points = await readAllPoints(session.transport, session.worldId);
const narrationStatusById: Record<string, 'pending' | 'ready' | 'failed' | 'missing'> = {};
for (const point of points) {
  narrationStatusById[point.pointId] = (await session.transport.execute(
    'narration_get', {}, { worldId: session.worldId, pointId: point.pointId },
  )).data.narrationStatus;
}
setEntries(historyEntriesFromPoints(points, { narrationStatusById }));

// submit 的 catch（把硬失败与校验提示分开）
catch (error) {
  setNarration(narrationFailed(
    error instanceof Error ? `${error.name}: ${error.message}` : String(error),
    { previousText: lastAccepted.current?.text ?? null },
  ));
}

// 渲染
<WorldLocalLayout
  title="龙族 · 自由一日"
  subtitle="全部在浏览器本地运行 · 服务器只负责存档"
  meta={<button onClick={reset}>重新开始</button>}
  banner={warning ? <div role="note">{warning}</div> : error ? <div role="alert">{error}</div> : null}
  narration={<NarrationView state={narration} />}
  controls={
    <GameControls
      value={input}
      onChange={setInput}
      onSubmit={(text) => void submit(text)}
      phase={phase}
      busy={busy}
      paused={paused}
      // 06 的会话接线确认前不要传 pause/resume/cancel：组件会显示“尚未接入”
      // onPause={...} onResume={...} onCancel={...}
    />
  }
  status={statusView ? <WorldStatusPanel status={statusView} /> : <p>正在读取状态…</p>}
  history={
    <HistoryPanel
      entries={entries}
      headPointId={context.world.head.pointId}
      selectedPointId={selectedPoint}
      onSelect={setSelectedPoint}
      // 正文重生成尚未有安全会话路径，先不传 onRegenerate
    />
  }
  progress={
    <ProgressStatus
      online={typeof navigator === 'undefined' ? true : navigator.onLine}
      save={saveStatus}          // 页面把 save() 的 saving/saved/failed 映射进来
      sync={null}                // 07 接入前保持 null，组件显示“同步尚未接线”
    />
  }
/>
```

`saveStatus` 由现有 `save()` 改造为：

```tsx
setSaveStatus({ state: 'saving' });
try {
  localStorage.setItem(SAVE_KEY, JSON.stringify(snapshot));
  setSaveStatus({ state: 'saved', savedAtLabel: new Date().toLocaleTimeString() });
} catch (error) {
  setSaveStatus({ state: 'failed', error: error instanceof Error ? error.message : String(error) });
}
```

## 6. 限制（如实说明）

- **未接真实模型/真实存档**：预览页全是手写示例数据；本线没有跑模型推理，没有占用 GPU，也没有验证真实 narration 的语义质量。真实页面接线由主 agent 完成。
- **暂停/继续/取消回调**：`LocalGameSession.pause()/resume()/cancel()` 目前会各自调用 `driver.run()`；如果与正在等待的 `submit()` 并发调用，可能重入 `step()`。本线只提供按钮与禁用原因，未改 session/controller。请等 06 的会话串行化接线后再把这三个回调传进来；在此之前保持不传，界面会明确显示“当前会话尚未接入暂停/继续/取消”。
- **正文重生成**：没有安全的 claim/regenerate 会话路径，默认禁用并显示原因。02/06 提供后再接 `onRegenerate`。
- **历史正文状态的读取成本**：接线片段对每个时间点调用一次 `narration_get`。本地 transport 是内存读取，量小；如果时间点很多，页面应缓存或只读最近 N 个，但不要把未读状态标成 missing。
- **`worldStatusFromState` 的房间解析**：与 `local/prompt.ts` 的容器遍历同规则，但为了不依赖主 agent 正在改的 prompt.ts 在组件目录内复制了只读实现；两处规则若变化需要同步（prompt 的语义来源仍是 state kernel）。
- **07 分叉元数据**：`ForkOption` 接受 `snapshotId/parentSnapshotIds/revision/savedAtLabel`，与 07 的任务书写法兼容；最终字段名以 07 completion 为准，只需在页面做一层映射，组件不解析 payload。
- **06 快照**：组件不实现持久化、恢复或互斥；`ProgressStatus` 只显示页面给的保存/同步状态。
