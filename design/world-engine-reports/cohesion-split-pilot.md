# 职责拆分最小对照：u240 成句 + 独立整合模型（2026-11-04，未训练）

先说清两件事：

1. **整合模型用的是现成替身**（qwen2.5:7b，本机 ollama，温度 0，220 token 上限），不是最终小模型。它的成绩只能当**能力上界**看。
2. **这个对照混淆了两个变量**：职责拆分，和模型规模（7.6B vs 77M，差约 90 倍）。所以本轮**不能**把差异归给“拆分有效”。

## 1. 设置

| | A 臂 | B 臂 |
| --- | --- | --- |
| 事实成句 | u240（贪心，逐事实） | **同一批 u240 短句**（逐字复用） |
| 组织 | 现有两层编辑（保守合并 + 已授权“随后”） | 独立整合模型改写 |
| 授权信息 | 同一份：地点／可见／场景／可连接关系 | 同一份 |
| 禁止项 | 编辑层不改内容 | 提示词明确禁止新增人物／物件／动作／感官／事件／目的／因果／时间关系，禁止改顺序、禁止省略，只在标注的相邻两条之间用“随后” |

20 个完整源：10 个真实回合（5 条事实）＋8 个诊断源（3–4 条，覆盖同主体连续／跨主体交替／多对象）＋2 个双项事实单元。两侧输入完全相同。

## 2. 结果

| 指标 | A（u240＋编辑） | B（7B 替身整合） |
| --- | --- | --- |
| 事实保持（机械词级 + 人工） | **20/20** | **14/20**（另 1 条替换物件、2 条改顺序） |
| 未授权“随后”（无关系授权的 10 个源里） | 0 | **6**（v02、v03、v05、t01、t05、t19） |
| 重复（字面） | 5 | 2 |
| 新增内容 | 集中在单句末尾（u240 旧缺陷） | **每个源都有**：场景铺陈、解释性从句、目的与推测 |
| 总字数 | 909 | **1633**（+80%） |
| 耗时 | 约 0.5 s／源（77M，CPU）＋编辑 <1 ms | **1.5 s／源均值**（7B 量化，CPU，总 30.0 s） |
| 连贯性（人工 1–5） | 约 2 | 约 4 |

连贯性评分要打折扣：A 的“逐句罗列”和 B 的“段落叙事”风格差别太大，随机顺序也遮不住，**这是弱盲评**，只能当方向参考。

## 3. 逐条问题（B 臂）

| 源 | 问题 |
| --- | --- |
| fixture-r2 | 事实 `林川的灯罩蒙了灰` 被改写成 `铜灯的光晕被一层薄灰所蒙蔽`——**换了物件**（灯罩→铜灯） |
| fixture-r4 / train-r4 | **改了顺序**：把“脸色发白”从第 2 条挪到末尾 |
| v05 | 无关系授权却写「随后，塔顶的灯还亮着，什么也没有再发生」 |
| t05 | 无关系授权却用了两次“随后”，并加「他仔细检查了」「钟声在雾中回荡，警示着可能的危险」 |
| v06 | 加「两人皆行走在潮生巷中」「纸灯笼、油纸伞与鱼筐映在巷中」「排水沟旁的墙根上干纸散落」（干纸不在可见清单） |
| fixture-r5 / train-r5 等 | 加「似乎在提醒他这天的劳碌」「仿佛刚从一场雨中归来」这类推测 |

A 臂的已知缺陷（`指节发白，指节发白`、单句末加「玻璃上不再有雾」）原样保留，没有因为对照而改。

## 4. 这一轮说明了什么

- **拆分能带来连贯性**：同一个事实集，交给一个专门做组织的模型，读起来确实像段落；A 臂仍是句子罗列。
- **但也把接地压力全部转移到了整合模型**：替身模型会把事实换成相邻物件、会改顺序、会在没有授权的地方补“随后”、会补目的和推测。也就是说，“独立整合模型”并不是天然的守规矩角色。
- **不能据此评价拆分本身**：7.6B 比 u240 大两个数量级，连贯性提升里有多少来自规模、有多少来自职责分离，本轮分不开。

## 5. 下一步该验证什么（不立刻训练）

要让这个对照有意义，需要把规模变量按住，两个可选做法：

1. **同规模替身**：用 0.5B 级模型（本机已有 qwen2.5:0.5b 的 GGUF）做整合，先看它在同样提示词下的接地表现——它大概率写不通顺，但能说明“小模型做组织”的难度基线；
2. **约束更强的输入形式**：把事实逐条编号、只允许“合并/指代/替换同义/插入已授权背景”，并给出可插入背景的白名单，看替身模型是否能在不越界的前提下提升连贯性。

只有这两步里至少一步显示“同规模下拆分仍有收益”，才值得为整合模型准备训练数据。**本轮不训练、不补数据。**
