## 3. 先看硬违规：11 / 20

### 3.1 关系端点：10 / 10 个有关系授权的源全部违规

fixture-r1..r5、train-r1..r5 都有 `f2→f3` 的 `before` 授权。A1 里是“随后，陈默/叶知微的鞋底沾了泥。陈默/叶知微的袖口湿到肘部。”——f3 是关系目标，必须保留句界。B 臂的实际写法：

**fixture-r1**

- A1：林川的袖口沾了雨，指节发白。周宁的斗篷下摆湿了一片。随后，陈默的鞋底沾了泥。陈默的袖口湿到肘部。
- B：林川的袖口沾了雨，指节发白；周宁的斗篷下摆湿了一片，陈默的鞋底沾了泥，袖口湿到肘部。

问题：

1. f2（周宁）和 f3（陈默）被逗号并进同一句，f3 的端点句界被跨过；
2. “随后”被删除，关系不再可见；
3. f4 的“陈默的”被省略，只剩“袖口湿到肘部”。

其余 9 个关系源也都有端点合并：`f2/f3/f4` 合并、f4 主语省略、`随后` 删除或移动。train-r2 把“随后”挪到 f4 前，train-r5 把 f2/f3/f4 全并成一句；train-r3 还多一处主体/对象换（见 3.2）。这些都不是“保留端点句界”。

这不是“连贯性换一点事实”能解释的：关系端点是本轮 v2 的硬边界，10/10 违规意味着 B 臂在这条规则上没有可靠行为。

### 3.2 train-r3：主体/对象被换

- A1：沈砚被雨打湿半幅，袖口开了线。顾行舟的指缝里塞着泥。随后，叶知微的鞋跟磨塌了。叶知微的裤脚沾了铜油。
- B：沈砚被雨打湿半幅，袖口开了线；顾行舟的指缝里塞着泥，也沾了铜油。随后，叶知微的鞋跟磨塌了，裤脚沾了铜油。

“沾了铜油”原本是 f4（叶知微的裤脚），B 把它同时接到了顾行舟身上。这不是省略，是**把一个人的结果换到另一个人身上**；同时 f2 被跳过、端点被合并。硬违规。

### 3.3 v01：谓词/顺序被改

- A1：沈砚从潮渡上来。韩渡把松脱的钟绳重新系紧。沈砚把警示灯扶正。韩渡的袖口沾了盐沫。
- B：沈砚从潮渡上来。韩渡把松脱的钟绳重新系紧，也把袖口沾了盐沫。沈砚把警示灯扶正。

“韩渡的袖口沾了盐沫”是外观变化，B 改成“把袖口沾了盐沫”，变成动作/对象关系；同时 f1 和 f3 跳过 f2 并列。硬违规。

### 3.4 两条降级：t01 和 v05 不判硬违规

**t01**

- A1：沈砚把潮汐簿缺的那页补全，指尖沾了墨，把簿子合上推到桌角。
- B：沈砚把潮汐簿缺的那页补全，指尖沾了墨；把簿子合上推到桌角。

复核：全段只有沈砚一个人；“把簿子合上推到桌角”的主语可以唯一恢复，中文允许同主体承接。**不判残句，不判硬违规。** 但账本仍错：标成 `coord/1`（同主体）并漏 f1。文本因分号略顺，记“略有改善”，账本不可用。

**v05**

- A1：叶知微的袖口沾了铜油。沈砚的手背上沾了铜油。叶知微把灯罩擦得透亮。塔顶的灯还亮着，什么也没有再发生。
- B：叶知微的袖口沾了铜油，沈砚的手背上也沾了铜油。叶知微把灯罩擦得透亮，塔顶的灯还亮着，什么也没有再发生。

复核：人物和场景物件并成一句，但两个主体都显式；没有新增时间/因果/目的关系，没有改变归属，没有产生歧义。按“不能仅凭主体类别不同判违规”，**不判硬违规，记 `review` / 持平。** 账本仍错：`seg/1` 只列 f2，漏 f3。

结论：这两条不再计入 11 个硬违规；但它们也不证明组织能力（t01 账本错、v05 只持平/复核）。

## 4. 账本错误：文本可能合法，账本不可信

这一栏和硬违规分开，因为账本是“待核对声明”，不是正文本身。典型：

**t19（文本合法，账本错）**

- A1：阿棠的袖口沾了鱼鳞。沈砚的外袍下摆沾了泥水。阿棠把银鳞鱼装进鱼筐。沈砚把油纸伞收拢靠在摊棚边。
- B：阿棠的袖口沾了鱼鳞，沈砚的外袍下摆沾了泥水。阿棠把银鳞鱼装进鱼筐，沈砚把油纸伞收拢靠在摊棚边。

两处跨主体并列都保留了姓名、顺序和事实内容，**文本是合法 v2**；但账本把整段标成一条 `recast/1`，`factIds=[f0,f1,f2,f3]`。按 v2 应该是两条 `coord/1`。文本略有改善（四句变两句），但账本不能用来归因。

**v06（文本合法，账本错）**

- A1：阿棠的鞋底沾了湿石板的水。沈砚的袖口沾了雨。阿棠把纸灯笼扶正。
- B：阿棠的鞋底沾了湿石板的水，沈砚的袖口沾了雨。阿棠把纸灯笼扶正。

一处合法跨主体并列；账本同样标成 `recast/1` 多事实。文本略有改善，账本错。

**v03（只改标点，账本多报/漏报）**

- A1：沈砚把潮汐簿缺的那页补全。叶知微把干纸码成一小摞，指尖沾了墨。四下安静，没有新的事情发生。
- B：沈砚把潮汐簿缺的那页补全。叶知微把干纸码成一小摞，指尖沾了墨。四下安静；没有新的事情发生。

只把 no_change 事实的逗号改成分号，文本持平；账本标成 `recast/1`，多报 f0、漏报 f2。

**t05（文本可读，账本同主体/漏报）**

- A1：韩渡把松脱的钟绳重新系紧，把雾警钟敲响，手背上沾着盐沫。
- B：韩渡把松脱的钟绳重新系紧，把雾警钟敲响；手背上沾着盐沫。

分号后“手背上沾着盐沫”省略了“韩渡的”；文本可读，但账本标成 `coord/1`（同主体）并漏 f2。按 v2，这是 `seg/1`/`ref/1` 的复核项，不是跨主体并列。

账本问题汇总：3 个 `recast-multi-fact`、8 个 `coord-not-contiguous`、3 个 `coord-same-subject`、7 个漏 f2、2 个漏 f3、2 个多报、2 个 `source-not-in-A1`。**模型自报的操作类型不能直接用来算组织收益。**

## 5. 背景与局部衔接

- **背景 `bg/1`：0 / 20。** 提示词里明确说“背景可选，如果能让段落更清楚可以用”，模型一次都没用。5 例目标里的“浓雾里 / 清晨的薄雾 / 棚下散着光”在 B 臂里全部没有出现。
- **指代 `ref/1`：0 / 20。** t01 分号后省略主语，但全段只有沈砚，主体可唯一恢复；不是硬违规，账本仍标错。
- **断句 `seg/1`：1 / 20，账本漏 f3**（v05 的人物-场景并列；复核未发现新增关系/归属/歧义，不判硬违规）。
- 14 个 `coord/1` 里，文本合法的有 t19（两处）、v06（一处）、v05（第一处）；v05 第二处是 `review`；其余是端点/同主体问题。

这和旧规划器试验的 0/20 背景使用一致：**“给了白名单”不等于模型会选。** 背景落点这项能力在本轮没有得到任何正面证据；不能把 t19/v06 的并列改善当成“背景任务已解决”。

## 7. 判定与下一步

| 检查 | 结果 |
| --- | --- |
| 20/20 JSON 可解析 | 是 |
| 0 个硬违规（语义/文本） | **否**：11 源有硬违规，10/10 关系源破坏端点 |
| 背景落点有正面证据 | **否**：0 个 `bg/1` |
| 账本可用来归因 | **否**：17/20 有 flags；t19/v06 文本合法但账本错 |
| 组织能力成立 | **否**：0 明显改善，3 略有改善但账本错 |

本轮**没有守卫臂**：模型原文 6/20 `pass`、3/20 `review`、11/20 `fail`；回退率 N/A；保留下来的组织收益按模型原文计，不经过回退。若下一轮加守卫，要按“模型原文合法率 / 回退率 / 回退后保留收益”三栏分开记。

所以：

1. **不训练、不建新确认集。** 这 20 源是开发对照；B 还没证明自己在合法空间内能改善表达。
2. **先修合法空间，再谈连贯性。** 两个具体方向：
   - 对端点做程序守卫/约束生成：端点句界、`随后` 位置、关系目标姓名开头，不满足就回退到 A1；但这会把“模型能力”和“程序兜底”混在一起，必须分臂记录。守卫回退是工程保护，不是模型改善；如果做守卫臂，要分别记录模型原文合法率、回退率、回退后保留的组织收益。守卫后的“零违规”不能作为训练依据。
   - 把 `bg/1` 单独做成一个任务/提示，不要和 `coord/1` 混在一次自由改写里；否则模型会继续用并列换连贯，完全不碰背景。
3. **账本不要直接信。** 下一轮可以让程序对齐 A1→B 生成账本，模型只写正文；或者要求模型按更小的步输出（一次一个操作），再由程序装配。当前“整段正文 + 自报账本”的失败率太高。
4. 只有在同一 20 源上把硬违规降到 0、且至少有一部分源出现合法的 `bg/1`/`ref/1` 后，才值得讨论小模型训练或新确认集。

本轮没有证明的事：背景落点（0 个 `bg/1`）、指代（0 个 `ref/1`）、账本可靠（17/20 有 flags）、合法空间内的稳定组织能力（0 明显改善）。即使 B 通过，也只证明组织能力，不代表自动端到端 workflow；本轮 B 未通过，所以连组织能力也还不能算成立。

本轮没有改 u240、没有接服务、没有加世界字段、没有训练、没有程序修复模型输出。
