# 方向案例复核与解码路线收口（2026-11-04，未生成未训练）

只用已有输出复核。结论：**没有一条能判为“明确方向错误”，撤回“新增方向错误”的判断**；束宽 2 保留为离线质量候选，不晋升，也不接服务。

## 1. 方向字段是什么

| 项 | 定义 |
| --- | --- |
| 字段 | 移动单元里的一行 `方向=上|平|下`，由材料生成时写入，与事实 `移动｜A→B` 一起给出 |
| 用途 | 输入要求原文：「需要表示高低时用**方向给的字**」——即要写高低，就用这个字；`平` 表示不主张高低 |
| 世界侧依据 | `world.json` 里每个地点的 `levels` 与子地点楼层：潮渡 1 层（栈桥／石阶／浅滩，石阶通向浅滩）、雾堤 1 层（堤面，堤上有石阶）、旧灯塔 **3 层**（石阶→旋梯→塔顶，原文写“再上塔顶”）、潮汐档案馆 1 层（“低矮砖房”） |

## 2. 逐条复核

### v13:f0（小回归、215 都出现）

- 事实：`叶知微｜移动｜潮渡→旧灯塔`，`方向=平`
- 输入要点：`地点=旧灯塔>塔顶`；`地点可见=铜灯罩、灯芯、抹布、擦铜油、铁链、备用灯芯`；`场景=夜；夜雾；塔顶铜灯已点亮`
- 输出：A `叶知微从潮渡一路走到旧灯塔脚下,抬头看了看塔身。` / B `叶知微从潮渡上来,走进旧灯塔。`
- 场景高度依据：**有**。旧灯塔 3 层，世界描述“石阶从巷侧通向旋梯，再上塔顶”；潮渡是河海交界的木栈桥，低于岸上与堤面。
- 判定：**方向含混**。B 的“上来”与“从水边进入三层塔楼”不矛盾；A 的“走到脚下”同样成立。两者都没说错世界事实，差别是 B 采用了趋向说法。

### t07:f0（小回归、215 都出现）

- 事实：`沈砚｜移动｜潮渡→雾堤`，`方向=平`
- 输入要点：`地点=雾堤>堤面`；`地点可见` 里**含“石阶”**；`场景=夜；浓雾；警示灯`
- 输出：A `沈砚从潮渡一路走到雾堤,鞋底在石阶边站了一会儿。` / B `沈砚从潮渡上来,蹲到雾堤的钟架下。`
- 场景高度依据：**有**。雾堤是“港口外侧石堤…堤上有石阶”，潮渡在堤下水面。
- 判定：**方向含混**（B 的“上来”有石阶依据）。但 B 另有问题：**“蹲到”是未授权动作**，这条的缺陷在动作，不在方向。

### t14:f0（小回归、215 都出现，两臂完全相同）

- 事实：`顾行舟｜移动｜潮渡→雾堤`，`方向=平`；可见清单同样含石阶
- 输出：A 与 B 都是 `顾行舟从潮渡上来,走进雾堤。`
- 判定：**方向含混**，且**不是束搜索引入**——贪心原本就这么写。

### t18:f0（215，两臂完全相同）

- 事实：`叶知微｜移动｜潮渡→旧灯塔`，`方向=平`
- 输出：A 与 B 都是 `叶知微从潮渡上来,走进旧灯塔。`
- 判定：**方向含混**，同样是贪心原有行为。

### d025（新确认集，束搜索独有）

- 事实：`沈砚｜移动｜潮渡→潮汐档案馆`，`方向=平`
- 输入要点：`地点=潮汐档案馆>长桌`；`地点可见=潮汐簿、铜灯、干纸、墨、笔架、门槛、天窗、长桌`（无台阶、无高处）；世界描述档案馆是**“低矮砖房”**
- 输出：A `沈砚从潮渡过来,走进档案馆。` / B `沈砚从潮渡上来,走进档案馆。`
- 场景高度依据：**否**。这是唯一一条场景里找不到高度依据的。
- 判定：**方向含混（最弱的一条）**。“从码头上来”在汉语里可以只是趋向（从水边到岸上），不算直接与“低矮砖房”冲突；但因为没有台阶或楼层依据，这个词在这里是**多余的添加**，属于表达风险。

### d027（新确认集，两臂相同）

- 事实：`叶知微｜移动｜雾堤→旧灯塔`，`方向=平`；旧灯塔 3 层
- 输出：A 与 B 都是 `叶知微从雾堤上来,走进旧灯塔。`
- 判定：**方向含混**，非束搜索引入。

### 附：d021（两臂相同的病句，与方向无关）

- 事实：`雾堤→潮渡`，`方向=下`
- 输出：A 与 B 都是 `顾行舟从雾堤下下到潮渡。` —— “下下”是重复造成的病句，两臂一致，属于既有缺陷。

## 3. 结论与收口

| 判断 | 结果 |
| --- | --- |
| 明确方向错误 | **0 条** |
| 方向含混 | 6 条（v13:f0、t07:f0、t14:f0、t18:f0、d025、d027），其中仅 d025 无场景高度依据 |
| 束搜索独有的含混 | 3 条（v13:f0、t07:f0、d025）；其余 3 条贪心同样如此 |

因此：

1. **撤回“新增方向错误”的结论**，改为**表达风险记录**：`方向=平` 时写出“上来”，与输入契约“需要表示高低时用方向给的字”不一致；世界事实层面不构成矛盾。
2. **束宽 2 保留为离线质量候选**，不晋升、不接常驻服务、不改解码配置。
3. 之前据“方向错误增加”下的“停止解码路线”结论**一并撤回**；解码路线按“待定”处理，是否继续只在需要时再议。
