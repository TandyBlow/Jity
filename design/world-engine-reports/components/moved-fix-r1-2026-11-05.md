## 6. 判定（2026-11-05 晚按修正后的契约重算）

| 条件 | 结果 | 依据 |
| --- | --- | --- |
| 1. 相对对照减少无依据追加 | **成立** | 三套题合计 moved 2 条、control 4 条（cf24 1/0、final24 1/2、moved24 0/2）；探针 moved 0、control 1 |
| 2. 事实不低于起点 C | **不成立（差 1 条修饰词）** | C 185/185；moved 机器 185/185、人工终判 184/185（`t22:f1` 丢“缠着”）；control 179/185 |
| 3. 非移动单元不退化 | **成立** | 非移动新增 moved 0、control 0；复读 0；语病 moved 3、control 3（起点 C 7） |

**结论：仍是不通过，但只剩一条**——`t22:f1` 丢掉事实值里的“缠着”。初版判定写的“三条都不成立”
是计数口径不一致造成的（见 `scoring-rule-r3-2026-11-05.md`），已更正；初版数字保留在各自文件里。
按约定不追加步数、不调参。

观测与解释要分开：

- **观测**：在这一轮里，移动句的无依据追加从 C 的 16 条降到 moved 的 2 条；同一时间里 moved 的无变化句
  出现了 5 条“站了一会儿/等了一会儿”（契约许可，不计新增）。这两件事同时发生。
- **解释**：“尾句被转移了”只是对上面两件事的一种解释，本轮没有证据把它和“模型整体换了口气”分开。
- 对照臂说明**额外续训本身也会减少尾句**（6/8 → 1/8），但它是另一个变量同时变化的结果，
  **不能据此量化**上一轮 C 的改善里有多少来自训练量。只能说：不能把 C 的尾句减少全部记在目标文本上。

另一个必须记下来的对照事实：control 多训 240 步、池子没变，事实掉到 83/73/24；
moved 在同一预算下保住 85/76/24。这是本轮唯一能归给目标修订的差别。
