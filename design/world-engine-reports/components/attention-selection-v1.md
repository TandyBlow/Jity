# 玩家关注驱动的内容选择：六项设计（2026-11-06，不训练）

## 1. 范围和结论

本轮只验证原始 workflow 的“选什么”：

- 同一组事实不变，只改变**玩家当前关注**和**上一段已述内容**；
- 观察选出的 `selectedFactIds` 是否随之改变；
- 先做人工选择和固定强规则基线，不跑选择模型，不训练；
- 所选事实的约定下游是冻结的 u240 逐条成句，再走现有编辑层；本轮**不运行** u240 或编辑层。

结果：六个条件里，固定规则和人工选择 **6/6 相同**，没有可解释的规则外收益。按约定，不训练选择模型，也不冻结模型对照协议。

这不等于“N2 没有职责”。它只说明：在这六个已经设计好的、关注词都能直接匹配事实的输入上，固定规则已足够；还没有证明需要模型。

与旧 N2 样本的区别：这里每组都有两个**成对条件**，事实不变，只改关注和已述，并且选择结果会互换；不是旧样本那种“没有取舍竞争”的单回合。与旧规划器、P、程序装配的区别：本交接的输出只有 `selectedFactIds`，不决定句界、不拼接、不改措辞；u240 和编辑层不参与本轮判断。

## 2. 三个组、六个条件

三组都复用各自包里的同一批事实。每组只改变两个条件字段：

- `attention`：玩家当前关注的自然语言；
- `attentionTargets`：把关注归一成对象词的实验输入（例如 `裴行舟`、`西栅桥`、`袖口`）；本轮不研究从原话里解析目标词；
- `priorNarration` / `alreadyNarratedFactIds`：上一段已经说过的内容。

**所有 attention 和 prior 文本都是人工实验条件，不是真实玩家记录。** G1/G2 的事实包来自已有 N2 开发材料（构造材料）；G3 来自已有真实管线回合 `train-r1`，但它的关注和已述条件同样是人工设定。

| 组 | 事实包 | 视角／授权 | 两个条件的关注 | 两个条件的选择 |
| --- | --- | --- | --- | --- |
| G1 | `n2-09`，全局，6 条事实 | 全知；must 2，optional 4，无 forbidden/uncertain | A：裴行舟的性子；B：沈拾的性子 | A：`f1,f2,f3`；B：`f1,f2,f4` |
| G2 | `n2-13`，主角裴行舟，6 条事实 | 视角裴行舟；must 2，optional 3，forbidden 1 | A：沈拾在忙什么；B：西栅桥的铜锁 | A：`f1,f2,f3`；B：`f1,f2,f4` |
| G3 | `train-r1`，主角沈砚，5 条外观事实 | 视角沈砚；must 0，optional 2，uncertain 3 | A：自己袖口湿没湿；B：自己指节怎么了 | A：`f0`；B：`f1` |

六个条件的具体事实、授权、已述内容、人工选择和理由在
`artifacts/world-components/organize-wording/attention-selection-v1.json`；这里不复制整份事实表。

### 组内必须保持的东西

- **必述全部保留**：G1/G2 的 `f1,f2`，G3 没有 must（空集）。
- **可见性未定不入池**：G3 的 `f2,f3,f4` 是同地他人外观，没有观察依据，三个条件都没有进入候选池。
- **禁止项不入池**：G2 的 `f5` 是他处任务，两个条件都没有选。
- **已述去重**：A 条件把对方的选择设为已述，B 条件反过来；选择因此互换。
- **不选全量**：六项选中的都只是 must 加一个当前关注的可选项，没有把池子全选。

## 3. 人工选择

人工选择只做三件事：

1. 保留 must；
2. 在已授权 optional 中，保留直接回答当前关注的那一项；
3. 省略已述、时间、无变化和不相关项；uncertain/forbidden 从一开始就不进池。

逐项理由：

| 条件 | 保留 | 省略 | 理由 |
| --- | --- | --- | --- |
| G1-A | f1 移动，f2 位置，f3 裴行舟的性子 | f4 已述；f5 时间；f6 无变化 | 当前关注裴行舟，f3 是唯一直接回答的可选项 |
| G1-B | f1，f2，f4 沈拾的性子 | f3 已述；f5 时间；f6 无变化 | 关注换成沈拾，选择随之换到 f4 |
| G2-A | f1 任务，f2 理智，f3 沈拾同地任务 | f4 已述；f5 他处任务；f6 时间 | 关注沈拾在忙什么，f3 是同地可见任务 |
| G2-B | f1，f2，f4 本地铜锁外观 | f3 已述；f5 他处任务；f6 时间 | 关注具体地点/物件，f4 是本地外观 |
| G3-A | f0 自己袖口 | f1 已述；f2-f4 可见性未定 | 关注自己的袖口，f0 是视角本人外观 |
| G3-B | f1 自己指节 | f0 已述；f2-f4 可见性未定 | 关注自己的指节，选择换到 f1 |

## 4. 固定强规则

规则 `R-attention-v1` 在看结果前固定，只做：

1. 所有 `must` 必选；
2. 从候选池删除 `forbidden` 和 `uncertain`；
3. 删除已在 `alreadyNarratedFactIds` 中的 optional；
4. 对剩余 optional，检查事实的 `name`、`text`、`goal`、`from`、`to`、`at`、`scope` 是否包含任一实验给定的 `attentionTargets` 对象词；
5. 有匹配就保留匹配项；没有匹配就不选 optional，**绝不退回全选**；
6. 保持事实原顺序。

这不是“全选”对手，也不是只读答案标签：它实际使用必述、授权、已述和关注关联。它没有用模型，也没有逐项加规则。

## 5. 规则差距表

| 条件 | 人工选择 | 规则选择 | 必述全留 | 禁止/未定 | 已述重复 | 全选 | 规则外收益 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| G1-A | f1,f2,f3 | f1,f2,f3 | 是 | 无 | 无 | 否 | 0 |
| G1-B | f1,f2,f4 | f1,f2,f4 | 是 | 无 | 无 | 否 | 0 |
| G2-A | f1,f2,f3 | f1,f2,f3 | 是 | 无 | 无 | 否 | 0 |
| G2-B | f1,f2,f4 | f1,f2,f4 | 是 | 无 | 无 | 否 | 0 |
| G3-A | f0 | f0 | 是（空 must） | 无 | 无 | 否 | 0 |
| G3-B | f1 | f1 | 是（空 must） | 无 | 无 | 否 | 0 |

**六项合计：人工＝规则 6/6；规则外收益 0。**

## 6. 这组设计能说明什么

**能说明：**

- 当关注对象和事实之间有直接词面联系时，一个固定规则已经能随关注和已述内容改变选择；
- 不需要选择模型来 reproduce 这六个选择；
- must、授权、已述去重、非全选这几条底线可以被同一个规则同时满足；
- G3 的 `uncertain` 项确实没有进入选择池。

**不能说明：**

- 不能说明真实玩家会怎样表达关注；
- 不能说明同义说法、间接指代、跨句关注、多人同名等情况下规则仍够用；
- 不能说明从真实玩家原话中提取关注对象词的能力；这六个 `attentionTargets` 是实验给定输入，不是解析器输出；
- 不能说明 N2 在更复杂任务里不需要模型；
- 不能说明这六项是系统能力或完整真实会话验收。

尤其要说明：G1/G2 的事实包是已有 N2 构造材料，G3 虽是真实管线回合，但只有 5 条外观事实；这六项的人工关注目标词/已述条件全部是实验设定，不是真实玩家记录。

## 7. 决定

按约定：

- 这六项没有可解释的规则外收益；
- **不训练选择模型**；
- **不冻结模型对照协议**；
- 不把“关注驱动选择”直接判成模型职责；
- 这只是一次小样本职责设计，不是 N2 通过，也不是完整会话验收。

本轮**没有运行 u240**，没有修改服务、编辑层或 `u240`；组织模块不加入。所选事实只是按约定可以送去冻结 u240 逐条渲染的 `selectedFactIds`，本轮不实际执行该下游。
