# 保守编辑基线（2026-11-04，未训练）

先回答一个问题：**“把同主体的相邻短句并起来”这件简单事，能不能拿到 12 对人工目标里的大部分收益。** 结果是能，所以暂时不需要训练编辑模型。

## 1. 编辑操作定义（规则，可回退）

按顺序判断，任何一步不确定就原样输出：

| 编号 | 规则 |
| --- | --- |
| R1 | 以 sourceId 分组，事实按 factId 升序，一条事实一句，**顺序不重排** |
| R2 | 主体取 `fact.name`；**只有人物主体参与合并**，物件与场景主体一律原样 |
| R3 | **相邻且同主体**才合并；第一句保留姓名，后续句删去句首姓名；若是“名字的X”则只删名字，保留“X” |
| R4 | 合并只加逗号，句末句号；**不插入任何时间、同时、因果词** |
| R5 | 跨主体交替、`no_change` 句、非人物主体：原样保留 |
| R6 | 合并后句内标点统一为全角逗号 |
| R7 | 前一句以“才发现/原来”收尾时**不合并**——后面接动作会被读成因果，事实没授权 |

R7 是实测加的一条：`v20` 若照 R3 合并，会得到“…松开手，才发现…那口气落回去了，把渡船推离栈桥”，读起来像“因为松了口气所以推船”，事实里没有这层关系。

## 3. 事实复核

对 25 个改动源逐条检查：每条事实的主体是否仍在、取值（含移动起终点）是否仍在、主体首次出现是否在其内容之前、主体出现顺序是否与事实顺序一致。

- **真问题 0 处**：无取值丢失、无归属改变、无顺序改变。
- 说明项 26 条：物件主体与“没有变化”句没参与合并，属规则设计内。
- **新增关系词 0 个**：全部 48 源编辑稿里，`再/又/随后/接着/然后/同时/正/这时/一边/跟着/于是/所以/因为/之后/先前` 的出现次数与原文完全一致（原文没有的，编辑稿也没有）。
- 一处已按你的修正执行：`v15` 原来人工目标里的“再”去掉了，改成三个并列“把”字句——事实列表顺序不等于事件先后，源数据没授权就不能加。

## 4. 语言对比（人工评，25 个改动源）

| 评级 | 数量 | 说明 |
| --- | --- | --- |
| 明显改善 | **15** | 3–4 句并成 1 句，读起来是一次连续动作，没有生硬处 |
| 略有改善 | **10** | 合并生效，但有两处小瑕疵（见下） |
| 无变化 | 23（未改动源） | 跨主体交替或单句源，规则不介入 |
| 变差 | **0** | 未发现 |

两类小瑕疵：

1. **外观句夹在动作中间**：`t02`「阿棠把银鳞鱼按大小分开装进两只鱼筐，袖口沾了鱼鳞，把空鱼筐摞到摊棚边上。」——中间那句是状态，夹在两个动作之间略打断节奏。规则按事实顺序合并，不改顺序，所以必然如此。
2. **合并后句子偏长**：`t16` 一句 46 字、5 个分句；`v14`/`v18` 也是 5 分句。读得下去，但缺少断句判断。规则没有“什么时候该断开”的依据。

## 5. 与 12 个人工目标比

7 个同主体源里 **5 个与人工目标逐字一致**（`v13`、`v16`、`v18`、`t05`、`t13`，只有逗号全/半角差异）。剩下 2 个：

| 源 | 差异 | 判定 |
| --- | --- | --- |
| `v12` | 人工用代词“她”，规则用省略主语 | 省略更安全（不用猜性别），人工目标应改 |
| `v15` | 人工有“再”，规则没有 | **规则对**，按你本轮修正，无授权不加顺序词 |

5 个跨主体源（`v01`/`t07`/`t09`/`t19`/`t21`）规则一律不动，与人工目标的差距全部来自“跨主体合并”。这部分按你的定性是**叙事关系授权问题**，不是语言能力问题。

## 6. 结论

- **同主体范围内，保守规则已经拿到人工目标的全部收益**：句数 161→116、相邻同主语 46→1、事实零风险、零新增关系词。
- 差距只剩两类，都不小到需要训练一个模型：代词/省略的选择（可规则化，且省略更安全）、跨主体合并（需要上游提供同时/先后/可重排约束）。
- **建议**：先采用这层规则做可回退的编辑层，不训练编辑模型。训练只在出现“规则做不了的判断”时再立项——目前只有一项候选：**合并后该不该断句**（长句 5 分句时没有依据）。
- 明确不处理、留作后续：句内语病（`t21` 双层“的”、`t23`/`t11` 同义重复）。这轮没混进来。
