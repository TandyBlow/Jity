# 理智事实的表达契约与规范化输入对照（2026-11-04）

不重训。先追溯语义、冻结契约、再用同一检查点做原输入 vs 规范输入的对照。

## 1. 追溯：放松／发紧确实来自理智数值方向

代码位置 `write_verbalizer_corpus.py:393`：

```python
if kind == "sanity_changed":
    return f"{fact['name']}｜状态变化｜{'放松' if fact['to'] > fact['from'] else '发紧'}"
```

所以训练事实行是**数值方向的渲染**，不是独立的情绪状态：

- `to > from`（理智上升）→ `状态变化｜<名>｜放松`
- `to < from`（理智下降）→ `状态变化｜<名>｜发紧`

源头 `corpus_v1/v0/v2` 里 20 条 sanity 事实全部如此，方向分布 **上升 15 / 下降 5**（与 verbalizer 20 条一致）。

**而我此前给 cf24、final24 生成的测试输入写的是 `理智｜<名>｜下降/上升`**：字段名（理智 vs 状态变化）和取值词（下降/上升 vs 发紧/放松）都不同。这是生成材料的写法差异，不是模型能力差异。

另外，训练目标只有 **6 种不同文本**（上升 3 句、下降 3 句），所以“方向对了”之后输出会接近逐字复现，这是另一个独立问题。

## 2. 冻结的表达契约（v1）

| 层 | 约定 |
| --- | --- |
| 事实层保留 | 主体（谁）、方向（升／降）；**不保留幅度与精确数值** |
| N4 输入字段 | `状态变化｜<主体>｜放松`（升）或 `状态变化｜<主体>｜发紧`（降）——与训练一致 |
| 正文必须表达 | 一个可感的方向：升用舒缓类（呼吸匀、松、散、落回去、慢下来、稳），降用收紧类（发紧、发闷、呼吸重、手指不听使唤、冷汗） |
| 允许省略 | 数值、幅度、具体次数、时间跨度 |
| 判 S（支持） | 出现与事实同向的可感描写，主体可辨认 |
| 判 C（反向） | 只出现与事实相反方向的描写 |
| 判 O（遗漏） | 完全没有身体或感受描写 |
| 判 O（含糊） | 只提到“胸口”“呼吸”但不带方向 |
| **违规：字段值泄露** | 把输入取值词当成谓语直接写在主体后面（“沈砚发紧”“沈砚下降”），或写出数值 |
| 不再判遗漏的情形 | 正文没写数值——**数值不要求文学文本承载** |

## 3. 规范化输入对照（不重训）

把固定诊断集里 6 条 sanity 单元按契约改写（只改事实行，其余字段一字不动）：

## 4. 判定

- **输入契约对之前的失败有实质贡献**：把字段名与取值词对齐训练后，方向支持从 0–1/6 变成 6/6。此前“理智 0/4”“1/4”的成绩不能用来判断模型能力缺口。
- **但契约不是全部**：431 在规范输入下仍把取值词当谓语写在主体后面（5/6），说明它在训练里学到的是“值词 + 身体描写”这种半模板；基线没有这个问题。
- **数据缺口仍存在，但性质变了**：不是方向学不会，而是**只有 6 种表达**，方向一多就会复现同一句。补数据的理由从“学会方向”变成“增加多样性”，不能混为一谈。
- 三个检查点在理智上**没有显著差异**（6/6 都达到），所以这一项不再支持任何配比结论。
