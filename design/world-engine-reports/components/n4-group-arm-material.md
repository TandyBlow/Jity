# 句组臂材料清点（2026-11-04）

结论先说：**现有磁盘上的句组材料不足以启动句组臂训练**。118 个共同源里只有 11 个带人工对齐的注解，能直接当独立组用的只有 10 组，且全部在 train，dev/holdout 一组都没有。

## 1. 有效源清点

| 项 | 数量 |
| --- | --- |
| 共同源（已排除 `n4n-03`、`n4n-15`） | 118 |
| 每源可表达事实数 | 1 条 37 源、2 条 57 源、3 条 22 源、4 条 2 源 |
| 含 2 条以上事实的源 | **81** |
| 带 `annotations`（人工句级对齐）的源 | **11** |
| 由注解生成的组 | 16 |
| 其中可直接当独立组使用的 | **10（全部 formal-train）** |
| dev / holdout 的组 | **0 / 0** |

分布：118 源里 98 train / 8 dev / 12 holdout。带注解的 11 源全在 train（`n4n-01…12`），所以即使只看“有没有组”，也凑不出 dev 选点和 test 评估。

## 2. 为什么现有注解不能直接当组目标

注解是**段落内部**的句子，带着前文语境写出来的。逐条检查 16 组：

| 问题 | 组数 | 例子 |
| --- | --- | --- |
| 同一条事实被两个注解覆盖 | 3 源（`n4n-07`、`n4n-09`、`n4n-12`） | `n4n-09` 的 f1 出现在两组里 |
| 目标不是完整句（注解在句中切开） | 2 | `n4n-04:g1` 结尾是“补完最后一个字，” |
| 目标以代词开头，单独成组时没有授权 | 5 | `n4n-05:g2` 以“他抓住钟绳”开头 |

也就是说，“每条必述事实恰好归属一组”和“目标不要求超出输入授权的指代”这两条，现有注解有 6 组过不了。这不是标注质量差，是它们的用途本来就是整段，不是独立组。

## 3. 缺口与代价

| 需要 | 现状 | 缺 |
| --- | --- | --- |
| train 组 | 10 | 至少再补 20–30 组 |
| dev 组（选点用） | 0 | 8 源 × 约 2.3 组 ≈ 18 组 |
| test 组（评估用） | 0 | 12 源 × 约 2.3 组 ≈ 28 组 |
| 衔接专项测试源 | 0 | 24 源 × 3–5 条事实，每源还要 1 段整段目标、约 3.2 个组目标、约 3.2 个单句目标 |

按每源 2.3 组估算，把 118 源补齐约需 **270 个组目标**；只做最小可用版本（20 train + 8 dev + 12 test 源）约 **90 个组目标**。另加 24 个衔接测试源的三套目标，约 **180 个**。

这些都必须人工按 factId 对齐，不能用标点切分代替：切分只能保证句子边界，保证不了“这句话讲的是哪条事实”。

## 4. 材料格式（已落地）

`artifacts/world-components/n4-group-material-r1.json` 里每条组记录：

| 字段 | 含义 |
| --- | --- |
| `groupId` | `源:g序号` |
| `sourceId` / `split` | 所属源与划分 |
| `factIds` | 有序事实 ID，组内顺序即生成顺序 |
| `input` | 只含本组事实的组输入：场景块不变，`事实：` 只列本组，`分组：` 只有 G1 |
| `target` | 该组的参考段落 |
| `planSource` | `corpus annotation (human)` —— 分组来自人工注解 |
| `valid` / `invalidReasons` | 是否满足“恰好一组 + 完整句 + 代词有授权” |

因为分组来自人工注解，若以后跑这个臂，必须标成**“人工计划条件下的句组臂”**，不能外推到自动 N3。自动 N3 的组要由 `n3_organize.py` 的规则从输入事实算出，届时组与注解可能不一致，需要另记。

## 5. 启动前必须满足的条件

1. **补组目标**：最小可用版 90 个组目标（20 train / 8 dev / 12 test 源），全部按 factId 对齐，且满足上面三条。
2. **三臂共用同一批源事实**：整段、组、单事实三套输入从同一份事实打包；组臂的目标不得引入新事件，不得要求输入未授权的代词。
3. **现有两臂检查点保持冻结**：组臂从同一干净基座训练，沿用源划分、曝光定义、dev 选点和每源总预算。补标若改动共同事实或参考语义，先记录受影响源，再判断是否需要重跑两臂基线。
4. **衔接测试单独建**：24 源，每源 3–5 条事实，覆盖同主体连续动作、两人交替、移动接动作、多对象描写；三臂输入分别打包，标签运行前冻结。

在这些条件满足之前，不给句组臂出训练配置，也不开跑。
