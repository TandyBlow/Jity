## 2. 冻结的训练协议

| 项 | 固定值 |
| --- | --- |
| 基座 | `IDEA-CCNL/Randeng-T5-77M-MultiTask-Chinese`；`model.safetensors` sha256 `5cdc572109cf25914b43fede20a6949b5fbf50b3a091a9c445fac60059bf5557`；`spiece.model` sha256 `c65feffa65ff0378759778193852083d23349cb1b40c906e9463a12f8076ff32`；77,440,384 参数。启动前重算一次，不一致就停，不换基座 |
| 数据 | `pairs-v2.jsonl` 24 train；源级隔离；不重排、不跨源拼样本 |
| 目标 | 同一源两臂逐字相同；只对目标 token 算 loss，prompt 段 mask |
| 序列 | 1 源/步；input+target 最长 512 token；右截断；两臂同口径 |
| 曝光 | 24 步/epoch；batch=1；梯度累积 4 → 6 次优化/epoch；20 epoch＝480 步＝**120 次更新**；不做上采样 |
| 优化 | AdamW，lr 5e-4，betas 0.9/0.999，eps 1e-8，wd 0.01，warmup 12 次更新，linear decay，clip 1.0，seed 13，fp32 |
| 评估 | 每 epoch（24 步）在 8 个 dev 源上算 dev loss＋逐事实 S/O/C/A；不碰 holdout |
| 选点 | 取 dev **事实层 S 率**最高的一轮；并列时取 dev loss 更低；**取消 patience，两臂都跑满 120 次更新**；恢复该轮；两臂同一规则。固定留出只在选点后跑一次，不因留出结果换点 |
| 解码 | greedy；max_new_tokens 128；无 beam、无长度奖励、无重复惩罚 |
| 记录 | 数据/权重哈希、完整配置、逐源原始输出、耗时；两臂同格式 |

**A 与 B_h 的唯一差别**：B_h 的 prompt 多一个计划块；基座、数据、目标、曝光、优化、解码、共同语境、授权关系全部相同。A 也能看到授权关系，不能只给 B_h。

### Prompt（两臂只差“表达计划”一段）

```
叙事任务。
地点=…
地点可见=…
场景=…
视角=…
授权关系=…（没有就写“无”）
事实（按顺序）：
f0｜…
…
要求：把全部事实写成一段连贯中文；按给定顺序；不新增人物、物品、地点、动作、关系；不写任务标题、数值、时长、字段名；不写代词，需要称呼时用姓名或承前省略。
正文：
```

B_h 在“正文：”前多：

```
表达计划：
{"groups":[…],"refs":{…},"edges":[…]}
要求：按计划的组和衔接写；组内可用逗号或分号，组间至少分号；edges 里 required 的关系必须写出，optional 可不写。
```

计划里没有动词、名词、标点、背景；`continuation/parallel` 只表示同主体组合／跨主体并列，不表示同时、先后或因果。

## 4. 判定与边界

1. **事实层先过**：holdout 上 B_h 只要出现 A 没有的新增事实、归属错或关系端点被拆，表达分再高也不记收益。
2. **再看表达层**：B3/B4 或人工 1–5；B_h 在 holdout 上高于 A 且事实层不退，才算接口信号，之后才训练组织模块、测 B_m。
3. **计划被遵守却没有改善**：只能说“**这次材料、计划和成句训练下未显示接口收益**”，不能直接否定接口本身。
4. **计划被忽略**：是模板/训练没让模型学会条件，不进入接口结论。
5. 人工计划条件下的收益是**接口上界**，不是系统能力；B_m 接近 B_h 才谈系统能力。
