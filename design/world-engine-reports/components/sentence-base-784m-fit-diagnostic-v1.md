## 6. `v20` 的逐 token 概率线索

只有 `v20` 是真正的遗漏，因此只对它展开了完整 target 与 actual 的 token 概率表。`t24` 没有漏事实，它的「衣角」是新增内容，不在这张遗漏表里。

`v20` 的目标和实际：

- target：`沈砚从潮生巷走到潮渡，心里松快了些，把渡船推离栈桥。`（26 个 token，含 EOS）
- actual：`沈砚从潮生巷走到潮渡,把渡船推离栈桥。`（20 个 token，含 EOS）
- target 总 logprob：`-12.467816`；actual 总 logprob：`-0.010294`。两者长度和内容不同，只能看局部，不能把总 logprob 当作“哪个更好”的总分。

关键位置：

| 位置 | target token | target 概率 | actual token | actual 概率 | 说明 |
| --- | --- | ---: | --- | ---: | --- |
| 刚过「走到潮渡,」 | `心里` | **0.006395** | `把` | **0.991850** | 模型在这里更愿意直接进入 f2「把渡船推离栈桥」，不是进入理智 f1。 |
| 理智短语后 | `,` | **0.000678** | — | — | target 在「松快了些」后要接逗号，这个逗号概率也很低；不是只有开头低。 |
| EOS | `</s>` | 0.999992 | `</s>` | 0.999985 | 两版最后都能正常结束；actual 的 EOS 在 f2 之后，**不是在漏项旁边提前结束**。 |

因此这次 `v20` 的线索是：**模型没有在理智位置选择 EOS，也没有被 EOS 截断；它把「心里松快了些」这一步跳过去，直接生成了下一个结果 f2，最后正常 EOS。** 低概率集中在理智短语的入口和其后逗号，而不是停止符。这个观察只能说明模型当时更偏向哪条路径，不能证明原因，也不能据此修输出。

## 7. 这回答了什么，没回答什么

回答：

- **训练组能写全**：134/134 组、231/231 事实，包含 1/2/3/4 事实组、同主体/跨主体和六种事实类型。
- **fixed 也能写全**：25/25 组、31/31 事实。
- 现有遗漏只剩旧 regression 的 `v20 f1`；另有 `t24` 的新增错误，不是遗漏。
- 所以“当前配置连训练组完整覆盖都没学成”这个假设不成立；这轮没有显示训练拟合是主要瓶颈。

没有回答：

- 为什么 fixed 全过、旧 regression 的 `v20` 会漏；样本只有一组，不能做因果归因。
- 训练组和 fixed 的自动通过不等于逐句语义审计通过；如果要做语义级“完全正确”，还需另一轮人工复核。
- `t24` 的「衣角」为什么会出现；它是新增内容，不是遗漏，未做逐 token 遗漏分析。
- 换更多数据、更多更新或另一个基座是否会修好；按用户要求，这次不训练、不扩数据、不训练组织模块。
- 这是否能外推到 77M 或其他模型；B-large-77 没有保存检查点，不能做同口径训练组诊断。
