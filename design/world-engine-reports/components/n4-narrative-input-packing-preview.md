# N4.0 结构化输入预览 v1（已审通过语料）

日期：2026-11-02。当前编号：**N4=叙事生成模型、N4.0=程序输入装配、N5=核对**。本文件验证 N4.0 的输出，不训练、不调用模型。

与旧文本输入的区别：不再预写“沈砚从潮生巷来到旧灯塔。”这类完整事实句；N4.0 输出的是**带 id/kind 的结构化记录**，句子由 N4 生成模型自己写。旧句子格式仅保留给冻结的 v2/v3 模型与字节回归。

- 输入 **287–390** tokens；目标 **75–99**。
- 旧 v2 模型 `max_input=160` / `max_output=96` 不适用；N4 新训练建议 `max_input≥448`（推荐 512）、`max_output≥128`。
- 12 例是开发集；训练需扩样与冻结留出。
