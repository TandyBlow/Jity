# 单事实臂基线冻结（2026-11-04，本轮结项）

## 1. 结论

**在当前 77M 模型和语料配置下，单事实生成明显优于多事实联合生成；句组训练没有解决保真与衔接问题，具体成因仍未确定。**

这不是“任务形状普遍最优”的证据：只有一个模型、一个世界、单种子。

## 3. “保真可用”的范围

只能理解为**可继续开发的底座**：整源仍有三分之一不干净（8/24），其中 4 条事实错误、4 条是事实都对但夹了未支持的陈述。距离直接交付还有差距。

## 4. 五条事实错误对应的失败类型

| 源 | 错误 | 类型 |
| --- | --- | --- |
| `t08` f1 | 顾行舟绕缆绳 → 写成阿棠 | 跨主体动作归属 |
| `t08` f3 | 顾行舟外袍沾泥 → 写成阿棠的外袍 | 跨主体外观归属 |
| `t16` f1 | 钥匙塞进油布包**内层** → 写成**外层** | 容器内／外方位 |
| `t21` f0 | 潮汐簿缺页边缘毛糙 → 换成“他等了一会儿，墙角那点发紧的感觉散了” | 退回通用模板，事实被替换 |
| `t24` f1 | 排水沟里面积了泥 → 写成“泥在泥里打滑” | 对象／地点绑定 |

另有 4 条**未经支持的新增内容**：`t01` 多出“又回到档案馆”（新增移动事件）、`t12` 多出“抱着一叠鱼筐”、`t15` 多出“抱着木桩”、`t23` 多出“在灯芯上结了锈”。这四条不能都归因成主客体错配：`t01` 是凭空加了一次移动，另三条是动作或状态挂到了不对的实体上。

## 5. 回归案例库

本阶段这些输出保留为回归案例，不再当训练材料：

| 用途 | 数据 |
| --- | --- |
| 事实错误回归 | `n4-cf24v2-manual-r1.json` 里 4 个出错源（`t08`、`t16`、`t21`、`t24`） |
| 未支持新增内容回归 | 同文件的 `t01`、`t12`、`t15`、`t23` |
| 原始输出 | `n4-cf24v2-{fact,paragraph,group}.json`、`n4-cf24-{fact,paragraph}-r1.json` |

**修复错误类型时不要直接对着这几条测试答案训练**：它们只用来判定是否修好，不进入训练集。修法应落在对应的能力上（跨主体归属、容器方位、对象绑定、模板回退），而不是让模型背下这几句。

## 6. 下一步优先级

1. 这五类事实错误（跨主体动作、跨主体外观、内外方位、模板回退、对象绑定）优先处理。
2. 衔接作为**独立问题**保留：句间无连接词、主语反复、清单感 3.6。不靠加长输出或放宽判据掩盖。
3. 句组路线维持归档，不再追加规则、解码约束或训练。
