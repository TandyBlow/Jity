## 1. 任务定义

输入：已提交事实表（编号 1..n）＋视角规则。输出：**要写进正文的事实编号集合**。

- 输出是选择，不是新事实：编号以外的内容不接受，未知编号记为无效 token。
- 三类标注（v2 程序定义；v3 人工独立标注见 §7）：
  - `must` 必述：主角自己的行动、玩家正在推进的任务结果或其理智变化；
  - `forbidden` 视角不可知：他处的变化、他人他处的私事；
  - `omittable` 可省：其余全部（由 `全部 - must - forbidden` 推导，不手工挑，避免标注遗漏）；
  - `target` 旧构造选择（must ＋ 作者任选的 omittable）；**D1 后只作诊断**，不再作通过判据。
- **"全选"不是选择能力**：`selectAll` 单独记录，判据不以它为准。

## 2. 判据（D1 口径，跑前固定）

D1 把旧的 `target` 精确匹配降为诊断，硬指标改为 must 的召回与精度：

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| `mustRecall` | \|must∩sel\| / \|must\| | **硬性：每项 ≥ 0.95**（本集 must 为 2 条，即不能漏） |
| `mustPrecision` | \|must∩sel\| / \|sel\| | **硬性：每项 ≥ 0.85**；选 may 也计入分母（过度选择会降分） |
| `maySelectionRate` | \|may∩sel\| / \|may\| | **只报告**，不设门 |
| `forbiddenHits` | \|forbidden∩sel\| | **硬性：0**（视角不可见） |
| `invalid` | 非编号内容（含“编号＋解释”）、空输出、越界编号 | **硬性：0** |
| `targetExact` | sel == target | **诊断项**，不再作通过判据 |
| `selectAll` | sel ⊇ 全部事实 | 记录，不算通过 |

严格格式不变：允许可选 `编号：` 前缀，其后只允许数字与逗号/顿号/分号分隔，末尾可有一个句号；其它任何文字都会使该答案失效。

> 预登记失败分支（D1，现在就定）：若 v3 上 `P1-rule` 仍 must-recall=1.0 且 must-precision≥0.85，则 N2 模型臂降级为规则臂＋人工抽检，产能转 N3/N4；要复活模型，必须先造更难的样本（多主角任务竞争、秘密、跨人物目标），不得在合成集上刷。

## 3. 开发集（v2）

- A 主角移动后视角：自身移动＋任务必述，目的地变化可选，**他处变化与他人的情绪不可知**（4 项）；
- B 地点受限视角：本地任务/理智必述，本地变化可选，他处移动不可知（4 项）；
- C 全知视角：无禁止项，冗余时间/空点/他人情绪可省（4 项）；

### 4.3 观察（按 v2 证据）

1. 全选仍被判据正确扣分（16 次禁止项命中，pass 4/16）。

## 5. 结论与下一步

- **N2 未通过（D1 口径）**：六臂都没有达到 must-R≥0.95 且 must-P≥0.85；Qwen 仍有 9 次视角违规，Randeng 仍是空选择/无效内容。
- 视角约束本身是**程序可判定**的（P1-rule 证据），但 must 口径下 P1-rule 的 must-P 只有 0.433：它不能替代“必述选择”。N2 的价值在**显著性与省略判断**，而显著性口径要由 v3 独立标注确认，不能再用 `target` 精确匹配。
- **D1 失败分支未在 v2 触发**；v3 标注与 κ 冻结后再判。若触发，N2 模型臂降为规则臂＋人工抽检，产能转 N3/N4（D1 原文）。
- 模型路线（v3 冻结后才开始）：编码器打分头（事实条目×视角→must/may/omit），输入含视角字段与事实位置；生成编号的形态（M1/M2）两轮均未通过，不优先。
- 数据纪律：训练与调参用开发集；**N4 独立留出集保持封存**，不与 N2 混用。
- 在 v3 冻结、预登记判据与独立留出前，不宣布 N2 通过。
