# 编辑层冻结与上游关系授权核查（2026-11-04）

两件事：① 把编辑层的两条规则改准并接入（可回退）；② 查清现有事实到底授权了哪些叙事关系，用来决定跨主体衔接怎么写。

## 1. 规则修正

**R1 顺序**：改为**按输入给定顺序**，不再按 `factId` 字符串排序。原实现用 `sorted(key=factId)`，`f10` 会排到 `f2` 前面。现在完全不排序，测试 T1 用 `f2 / f10 / f1` 的乱序输入验证输出保持 `f2→f10→f1`。

**R3 所有格**：操作拆成两种并分别记录。

| 原文 | 结果 | 操作名 |
| --- | --- | --- |
| 阿棠把抹布塞进鱼筐底下。 | 阿棠把抹布塞进鱼筐底下，… | — |
| 阿棠**的**袖口沾了鱼鳞。 | …，**袖口**沾了鱼鳞。 | **删姓名＋的** |
| 叶知微换好塔顶的灯芯。 | …，**换好**塔顶的灯芯。 | 删姓名 |

原先两者都记成“删句首主语”，会把“删了名字留下‘的袖口’”这种错法掩盖掉。现在 22 处所有格删除、23 处动词短语删除分别记录，并逐条检查**所有者在本句内仍可无歧义恢复**（姓名的位置必须在该名词短语之前）——检查结果 0 处问题。

## 2. 接入形态

| 要求 | 实现 |
| --- | --- |
| 保留原稿、编辑稿、操作记录、编辑器版本 | 每源输出 `{original, edited, ops, fallbacks, version, changed}`，`version = "edit-layer/2"` |
| 开关 | 调用方决定是否用 `edited`；结构体同时给 `original`，可整源回退 |
| 异常回退原稿 | `fallbacks` 记录原因：非人物主体、主体名出现多次、姓名不在句首、删姓名＋的后不成句、删主语后过短、合并时所有者不可恢复 |
| 只补边界检查 | 48 源重跑，输出与 v1 **逐字相同**（0 处差异），仅操作记录与回退原因变细 |
| 同主体层冻结 | 跨主体、物件主体继续原样输出 |

回归测试 `test_conservative_edit.py` 7 条全过：顺序、所有格、主体不明回退、物件不合并、跨主体不动、反思句不并、无新增关系词。

**一处必须承认的限制**：`无新增关系词`只是词频检查，不是语义安全证明。R7 就是反例——不加任何关系词，只要把“松口气”和“推船”并进一句，读起来就有了因果。这层靠人工复看 25 个改动源（明显改善 15、略有改善 10、变差 0）把关，不靠词频。

## 3. 上游关系授权核查

问题：现有事实是否明确提供**同时、先后、因果、允许重排**的依据。

查了全部 215 个契约单元的事实字段与取值：

| 事实种类 | 数量 | 带的信息 | 是否含时间/因果关系 |
| --- | --- | --- | --- |
| `moved` 移动 | 18 | 主体、起点、终点、方向（上/下） | 否 |
| `outcome` 结果 | 101 | 主体、动作短语 | 否 |
| `appearance_changed` 外貌变化 | 78 | 主体、状态短语 | 否 |
| `sanity_changed` 状态变化 | 6 | 主体、升/降 | 否 |
| `no_change` 无变化 | 12 | 无 | 否 |

字段全集：`factId / kind / name / from / to / direction / text / entityGroup / resultText`。

- **没有任何字段表示同时、先后、因果或可重排**；
- 事实取值里关系词出现 **0 次**；
- `factId` 只是标识符，不是先后声明；
- `entityGroup` 只是 `characters / objects` 这类实体分类，不是时间分组。

**结论：表达层现在不能合法写“同时”“随后”“因此”，也不能擅自重排事实。** 之前那 5 个跨主体源想读顺，需要补的正是这些未授权的关系。

## 4. 表达层现在能合法用什么

不是一无所有，有三样是数据本身就授权了的：

| 依据 | 来源 | 能支持的写法 |
| --- | --- | --- |
| **同一地点** | 48 个源**全部**共用同一 `地点=` 与 `地点可见=` | 用地点做共同背景把不同主体串起来（“钟架边，……；台阶下，……”），不声称时间关系 |
| **同一物件** | 事实取值里出现的物件（如钟绳同时出现在两条事实里） | 用同一物件做承接（“钟绳绷直了……他又把钟绳绕回钟架”），物件身份来自事实 |
| **同一视角** | 48 个源**全部**同一 `视角=`，且输入要求写第三人称 | 视角人物作为观察者出现；但“他看见／他听见”是新增感知事件，**需你决策是否算授权** |

**暂不可用**：同时、先后、因果、重排。

## 5. 下一步要你定的两件事

1. **视角是否授权感知动词**：把“沈砚看见韩渡系钟绳”算合法，还是算新增事件？这决定跨主体衔接能不能借视角人物的观察来组织。
2. **上游能不能补关系字段**：如果希望跨主体读起来连贯，最省的做法是让上游在事实里加一个“同一轮/先后”的显式标记（例如 `relation: same-turn` 或 `order: 1,2`），表达层才有依据。这是数据契约改动，不是表达层能自己解决的。

在这两个问题有答案之前，跨主体继续原样输出，不再加例外规则。
