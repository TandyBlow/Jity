# 确定性展示的端到端只读预览

日期：2026-11-06。只读，**不接页面、不启用模型句替换、不训练**。本版适配器在此冻结。

## 1. 状态从哪来：优先生产 `replay_state`

| 来源 | 什么时候用 | 报告里怎么写 |
| --- | --- | --- |
| 生产 `replay_state` | **优先**。沿链从根点重放，重放过程中自己校验每一点的状态摘要 | `source=replay`、`replayOk=true` |
| 检查点 | 重放不可用时。仅当检查点摘要等于该点位登记的摘要 | `source=checkpoint` |
| 都不行 | 报缺口，**不出句、不猜起点** | `gap: state not recoverable` |

**检查点缺失不再等于状态不可恢复**。夹具里 p2 的检查点被删，p3 的前驱检查点也没了；
两者都靠重放拿到了状态，事实照常展示。

摘要比对与重放验证分列，不合并成一个“校验通过”：

- `currentDigestMatchesPoint`：检查点字符串与该点位登记的摘要是否一致；
- `replayOk`：重放是否跑通；
- `replayAgreesWithCheckpoint`：重放结果与检查点是否一致（没有检查点时为 null）。

## 2. 夹具覆盖

| 点位 | 造了什么 | 预览结果 |
| --- | --- | --- |
| p1 | 移动＋理智下降 | `林川从走廊到门厅。`、`林川的理智下降（10→7）。`，前驱 root_fx |
| p2 | 外貌＋理智置 0，**检查点删除** | 重放恢复；`周宁的理智下降（10→0）。`、`周宁：袖口沾了水。` |
| p3 | 移动，**前驱检查点删除** | 重放恢复；`周宁从走廊到门厅。` |
| p4 | 空 Δ | `第4点没有实体变化。`，范围＝该点位 |
| p5 | 理智 0→4 | `周宁的理智上升（0→4）。`——0 当值读 |
| p6 | 任务达成 | **未展示**，标 `notAChange`，不写“没有变化” |
| p7 | Δ 被篡改＋检查点删除 | **缺口**：`state not recoverable`，附 `LedgerMismatch: Replayed state differs from the committed digest` |
| world_2 q1 | 另一个世界、独立链 | 只读自己的 root_w2，**没有串读 world_1** |

同一前驱分两支**在契约里做不到**：`world_points` 有 `UNIQUE(world_id, previous_point_id)`，
一个点位只有一个后继。所以用“两个世界各自一条链”代替，验证读不到对方。

前态缺实体/字段同样**造不出来**：生产 `apply_point` 对不存在的实体直接拒绝
（`KernelViolation id_unresolved`），角色又永远带 `sanity` 与 `position`。
这条边界在适配器层用测试覆盖（`test_missing_field_in_the_predecessor_is_a_gap`），并在报告里标明
“记录无法携带这种形状”。

## 3. 同屏预览长什么样

```
[world_1 p1 seq=1] prev=root_fx delta={"person_a": {...positionSet..., "sanitySet": 7}}
    show  林川从走廊到门厅。
          source=replay fields=positionSet,sanitySet,previous.position replayOk=True agrees=True
    show  林川的理智下降（10→7）。
          source=replay fields=positionSet,sanitySet,previous.sanity replayOk=True agrees=True
[world_1 p6 seq=6] prev=p5 delta={"person_a": {...tasksAchieved:["task_watch"]}}
    unshown  task delta has no display shape yet, so it is not shown
[world_1 p7 seq=7] prev=p6 delta={"person_a": {...sanitySet: 3}}
    gap      state not recoverable
```

一块一个点位：结构化增量、展示句、来源（`replay`/`checkpoint`、读过的字段、`replayOk`、`agrees`）、
未展示项、缺口。全量在 `fixture-preview.txt` 与 `real-preview.txt`。

## 4. 真实空 Δ 历史

`.local/world.db`：5 个世界、10 个点位、78 条提交记录。

- **10 条 `第N点没有实体变化。`**，0 缺口，全部 `replayOk=true`、`agrees=true`；
- Δ 全是空对象，所以移动/理智/外貌路径没有被真实记录覆盖——这一点沿用上一轮的说明，没有改动玩家数据。

## 5. 验收对照

| 要求 | 结果 |
| --- | --- |
| 支持的事实有准确展示和来源 | 夹具 10 条事实，全部带点位、前驱、实体、字段；真实 10 条 |
| 不支持的事实明确列缺口 | 任务 → 未展示（标明非“没有变化”）；p7 → `state not recoverable` |
| 恢复失败时不猜 | p7 不出句；缺字段时不出句 |

**17 条“误拒”的口径**：按你指出的，不再整体算误拒。移动类里“只有地名”“没抵达”若缺少移动或抵达断言，
就是合理拦截；要按完整命题逐条判，本轮没有重做这项重判，留作后续单列。
