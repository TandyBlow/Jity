## 4. 判定

预设标准：物件收益保留、移动恢复、其他能力不退步；若一边物件更好、一边移动更好，不选总分高者。

| 条件 | 422 | 431 |
| --- | --- | --- |
| 物件 18 全支持 | 是 | 是 |
| 确认 36 全支持 | 是 | 是 |
| 移动恢复 | 8/10 | **10/10** |
| cf24 干净源 | 20/24 | **22/24** |

**431 在三套材料上都不劣于 422，移动与 cf24 更好，物件与确认集打平。** 但两者差距只有 2 个源、1 条事实，属于单次运行的小差距，不能宣称 4+3+1 普遍更优。

按预设：本轮**不新增测试集**；出现“明确胜出”才做新冻结确认。431 领先幅度不足以称明确胜出，但它同时满足“物件保留 + 移动恢复 + 无退步”，所以记为新默认候选，**下一步再做一次新冻结确认（新写、先冻标签）**才替换正式版本。
