# 种子重复：lr 1e-4 / 120 步在三个种子上的波动

日期：2026-11-06。作业 241182，单卡 RTX 4090 D。起点 C（`08276c0c`），池子仍是 C 原始的
341 行，配置仍为 lr 1e-4、120 步、batch 8、4:3:1、fp32、AdamW。新增种子 `20261103`、
`20261104`，另取上一轮同配置的 `20261102` 作参照。

**结论先说：两个新种子都不满足预注册条件，因此 `1e-4＋120 步`不提升为“后续实验的优化配置”，
只保留“候选”身份。上一轮那个 0 损失、追加 1 条的结果没有复现。**

## 2. 逐条：两个新种子各丢了一条，但**不是同一条**

**20261103 → `m10:f0`（moved24）**，事实：叶知微 旧灯塔→潮汐档案馆

> 输出：`叶知微离开旧灯塔,沿着墙边站了一会儿。`

终点“潮汐档案馆”整个消失，句子停在“沿着墙边站了一会儿”，既没抵达，也把移动变成了停留。
机器判 O（起点有、终点缺）。

**20261104 → `t10:f3`（cf24）**，事实：沈砚 理智 12→9

> 输出：`沈砚按住胸口,那阵闷意没有散。`

下降被写成“没有变化”。机器判 O（无方向）。同一句式在这一轮只出现一次，而上一轮 3e-4/240
条件上出现了五次，说明它是这套目标教出来的一个可复用的“稳住了”句式，什么时候冒出来取决于种子。

两条损失落在不同单元、不同集合、不同事实类型（移动终点 vs 理智变化），**没有共同的输入诱因**。

## 4. 句法

- 20261103：`m10:f0`“沿着墙边站了一会儿”——残句，没有抵达动词。这是新破损（C 上是正常的）。
- 20261104：三套回归集上没有新破损；`m02:f0`“扶着木桩走到潮渡的栈桥边”是把木桩当支撑物，
  不合场景但不是句法错误。

## 6. 判定

预注册四条，两个新种子逐条对照：

| 条件 | 20261103 | 20261104 |
| --- | --- | --- |
| 新增人工事实损失 = 0 | ✗（1 条） | ✗（1 条） |
| 追加 ≤ 4/185 | ✗（7） | ✗（7） |
| 三套回归集无新句法破损 | ✗（1） | ✓ |
| 探针各列单报、不抵消 | ✓ | ✓ |

**两个种子都不通过，条件不提升。**按事先约定：报告波动、不挑最好的种子继续推进。
`1e-4＋120 步`仍是候选，不是配置基线，更不是质量通过的模型基线；探针上的句法退化照旧保留。

## 7. 这组数字能支持什么

**能支持的：**

1. 同一配置、同一数据、换种子，结果在**事实**上会差一条，在**追加**上会差 1 到 7 条。
   这说明之前把“16→1”当作配置性质是过度解读——那是三个样本里最好的一次。
2. 单次贪心生成 + 单种子，不足以支撑“这个配置更稳”的结论；后面任何比较都必须带种子重复，
   否则无法区分配置效应和抽样波动。
3. 失败点在不同单元之间漂移（`m10:f0` vs `t10:f3`），说明当前模型不是“某个形状没学会”，
   而是**在长句里维持全部成分的能力本就不稳**，哪一处先塌取决于采样。

**不能支持的：**

- 不能说 1e-4 比 3e-4 更好或更差（3e-4 只跑了一个种子）。
- 不能说事实损失和追加之间存在权衡（两个种子同时变差，不是一升一降）。
- 不能把这轮当作独立泛化验收：题目全部参与过设计，只是没参与这一轮的种子选择。

## 8. 下一步（等确认）

种子重复只检验了训练随机性，**独立泛化验收还没做**。基于本轮结果，有两件事需要决定：

1. 是否把“≥3 个种子、逐种子报告”固化成后续每一轮的默认要求（本轮之后我倾向于是）；

   在补齐之前不建议与普通增补比较。
