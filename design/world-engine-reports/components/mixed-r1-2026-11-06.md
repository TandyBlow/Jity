出发，配置与增补实验完全一致：240 步、batch 8、4:3:1、lr 3e-4、seed 20261102。

逐条人工确认是同一命题：名称字段、关系词、另一方、谓语都不变，改变的只是“名称写不写在值里”。

**一条要说明的既有情况**：aug:03 的值本来就是“压在上面的干纸露出边角”，两臂都不带名称。
所以 mix 的无名称行是 7/12（6 条新改 + 这 1 条），ctl 是 1/12。

**哈希断言换了**：这个设计里目标相同，跑之前的检查改成 id 相同、**目标相同**、输入在 6 行上不同。
旧断言“目标哈希必须不同”不适用于本轮，已在冻结文件里写明。

### 6.1 逐条看变化（相对 moved 起点）

**mix 修好的**

- `t22:f1`：moved“木桩的旧缆绳断了”→ mix“**缠在木桩上的旧缆绳断了**”。
  关系“缠着”和参照物“木桩”都在，句法成立。这是这一条第一次被写对。
- `t17:f0` / `v12:f0`：“穿过早市的人”→“走进早市”，事实外实体“人”消失。
- `t08:f2` / `t17:f2` / `v12:f2`：“挂着白汽”→“**沾了白汽**”，与事实一致（机器覆盖 1.00，不再是 REVIEW）。
- `v20:f1`：理智 9→12 写成“呼吸慢慢匀下来，胸口那点发紧的感觉散了”，方向对。
- `t11:f0`、`t13:f0`、`m19:f0`、`m20:f0`：移动句换成“走进/走到”，仍落在事实内。

**mix 新出现的（一条，必须单列）**

- cf24 `t21:f0`：事实“潮汐簿｜缺页的边缘毛糙”，moved 写“潮汐簿的缺页的边缘毛糙”（语病，但事实在），
  mix 写“**潮汐簿的边缘毛糙**”——“缺页”被书名替换掉了。
  机器判 S（覆盖 0.67），人工记为**事实替换**：说成了书的边缘，而不是缺页的边缘。

所以人工总数仍是 184/185，但**不是因为没损失**，而是因为 `t22:f1` 修好一条、`t21:f0` 又坏一条，
两相抵消。按本轮约定，“不得出现新的人工确认事实损失”这一条**不成立**。

## 7. 判定

| 项 | 结果 |
| --- | --- |
| 两侧都要好（≥10/12，每侧 ≥5/6） | **不成立**：合计 10/12 达标，但无名称侧 4/6，差一条 |
| 不能只看名称（关系 ≥11、句法破损 ≤1） | 成立：12/12、1 |
| 关系探针 ≥7/10 | 成立：10/10 |
| 回归·事实（不得有新损失） | **不成立**：`t21:f0` 新损失 |
| 回归·追加 | 成立：0 对 2 |
| 回归·语病 | 成立：2 对 3 |

**结论：不通过，两处不成立。**

1. 配对探针的无名称侧 4/6，低于事先写的 5/6。失败的两条是两种问题：np3 把“钟架”写成了
   “钟绳”的领属者（“搭在钟架的钟绳”），np6 复读塌缩成“压在门槛上,压在门槛上。”。
2. `t21:f0` 把“缺页”换成书名（见 6.1 节）。

人工总数仍是 184/185，但这是 `t22:f1` 修好一条、`t21:f0` 坏一条互相抵消的结果，
按本轮约定不能拿来抵消：**新损失要单列，总数不作为通过依据**。

## 8. 机制（有依据，但只到这一步）

混合范例确实教会了“从名称字段取参照物并插进句子”：无名称侧的通过数从 1/6 涨到 4/6，
有名称侧不退化（6/6），moved 的前缀堆叠没有回来（句法破损 3→1），关系保留 9/12→12/12。

但学会的只是“把名称放进句子”这个动作，不是“放进去时既不改关系也不动值里原有的名词”：
np3 用领属框架替掉了关系，np6 退化成复读，`t21:f0` 则把值里的“缺页”换成了书名。

`t21:f0` 的形态是**插入时覆盖了值里已有的领属名词**：值“缺页的边缘”本来有一个“X 的边缘”框架，
模型把 X 换成了名称“潮汐簿”，而不是在外层再加一层。np3 是同一件事的另一种表现：
值里没有名词可覆盖，它就把关系短语的宾语让位给名称（“搭在钟架的钟绳”）。两处都只有一条样本，
不能当成规律，但它们指向同一个机制假设：插入动作与“谁当领属者”共用了同一个位置。

## 9. 边界与未验证

- 配对设计**没有**等长对照，所以通过的部分只说明这个干预有效，**不说明长度无关**。
- 每组一次贪心生成，没有重复采样；11/12 与 10/10 是这组输入上的结果，不是概率估计。
- 三套题与两组探针都参与过诊断，本轮结论限定为回归改善，不宣称泛化。下一步才是未参与设计的新样本。
- `t21:f0` 这类“值内已有领属框架”的形状，本轮只出现一条，样本不足。
- 机器门对 `t21:f0` 判 S（覆盖 0.67），与 B 轮的“玻璃”同类：机器偏松，人工才抓住。
