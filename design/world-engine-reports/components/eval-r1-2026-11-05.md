## 1. 为什么先跑这一轮

上一轮两臂的结论建立在本机 CPU 上生成的数字。三臂训练改到了 HPC，如果只评测三个臂，
“和谁比”就没有同设备基准。所以把起点 u240 一起重跑，四个模型、三套题、同一张卡、同一套解码。

共 740 个单元：4 × (85 + 76 + 24)。

## 3. 评分与复核怎么分工

1. **机器评分**先出事实判定（S 支持 / O 覆盖不足 / A 错误 / REVIEW 待定）和机械标记。
2. **人工复核**再逐条读：把“与 u240 不同”或“机器有标记或非 S”的 71 个单元全部读过
   （cf24 27、final24 20、moved24 24），每个单元同时看四个模型的输出；u240 上已被复核过的条目
   因为输出与上一轮逐字节相同，判定原样保留。
3. 复核把两类问题分开记：**确认缺陷**（模型真的丢了事实 / 加了事实外的内容 / 句子不通）
   和**评分器误判**（机器判 S 但读下来不成立，或机器判 O 但读下来成立）。

cf24 与 final24 的 u240 行因为字节完全相同，直接沿用上一轮的逐条判读；三个臂的行全部重读。

## 5. 逐条判读的关键差异

**A 相对起点退化，而且是事实退化。** 两处都在移动句上丢起点或丢终点：

- cf24 `t09:f0`（早市→潮汐档案馆）：“叶知微到了潮汐档案馆” —— “从早市”没了。
- cf24 `t11:f0`（潮生巷→旧灯塔）：“沈砚沿着石阶走进旧灯塔” —— “从潮生巷”没了。
- moved24 `m14:f0`（档案馆→早市）：“在鱼筐前站住” —— 终点没了。
- moved24 `m24:f0`（早市→潮渡）：“船灯从早市过来…” —— 终点没了，且同一小句重复两次。

这四条都是机器判 O，人工读后确认，不是评分器误判。

**B 修好了 A 丢的起点，但自己丢了一个限定词，而且机器没抓到。**
cf24 `t23:f0` 和 final24 `v10:f1` 的事实都是“玻璃上蒙了盐雾”，B 写成“铜灯罩外/上蒙了盐雾”——
“玻璃”这个限定被吃掉，机器仍判 S。人工复核记为覆盖不足，所以 B 的事实支持数是
**cf24 84/85、final24 75/76**，不是 85/85 和 76/76——汇总表里那两列机器 S 只在机器口径下成立。
这是本轮唯一一类“评分器偏松”，共 2 条，都出在 B 的同一处目标上。

**C 在移动句上把尾句清干净了。** u240 的六条“到达后追加动作”（鞋底站住、抬头看塔身、
抱起一叠纸、鱼筐沾鱼鳞、钟绳绷直、帆布棚散光）在 C 上只剩 5 条新增，且都不在 moved24。
~~moved24 上 C 是 24/24 全净。~~ **更正**：C 在 moved24 上有 7 条同类尾句（见第 4 节脚注），
“全净”是初版漏记，已撤回。

**C 仍有三处语法问题是继承的，不是新出现的。** `t21:f0`“潮汐簿的缺页的边缘”、
`t22:f0`“系泊绳的泥水”、`t24:f1`“排水沟的里面”在 u240、A、C 上都是同一句，
B 改掉了前两处（`t21` 去掉一个“的”，`t22` 改成“系泊绳上泥水”），第三处四个模型都没改。
C 在 cf24 的语病数 4 比 u240 的 3 多，多出来的一条是 `t12:f0`“抱着一叠鱼筐”——量词错配，
属于新问题。

**无变化句整片换了口气。** final24 的 8 条 no_change 单元，u240 说“四下安静,没有新的事情发生”，
三个臂统一说“长桌上的东西都还在原处,屋里没有新的变化”（按地点换主语）。事实判定都是 S，
也没有新增事实；这是目标里教出来的固定句式，记下来但不计缺陷。附带好处是 u240 在
`v22:f1`/`v24:f1` 上“什么也没有再发生”的自我复读消失了。

## 6. 三组对照

| 对照 | 结论 |
| --- | --- |
| A → B（只修事实） | 人工终判事实 83→84，新增 17→10，语病 10→5。修目标里的起点/限定词确实把 A 的事实退化救了回来，但引入 1 处新的限定词丢失（玻璃），机器没抓到。 |
| B → C（再删尾句） | 人工终判事实 84→85（这 1 条差额来自 B 丢的“玻璃”，不是 C 新修好的东西），新增 10→5，复读 1→0；moved24 上两臂同样是 7 条尾句（初版记的“全净”已撤回）。**本轮只能说：在这个种子和预算下，完整修订优于保守修订。**两臂长度只差 1 个字（12.2 vs 13.2），所以新增减少不能归因于“尾句被删”这一个因素——更短、目标文本更干净、训练时的句子分布变化都混在一起，长度效应没有分离。 |
| C → u240 | cf24 事实持平（85/85），新增 6→5，复读 2→0；语病 3→4（多出 `t12:f0`）。final24 事实持平，人工严格 17→20，独立切片 41→42。moved24 上 C 与 u240 的尾句同为 7 条，u240 另有 2 处语病被修掉。**事实不劣于起点，表达更干净，但不是全面占优。** |

## 7. 判定

按事先写死的口径：

- **事实完整性不低于 A**：B、C 成立（85 vs 83），A 自身不成立。
- **B 优于 A 说明修事实有用**：成立。
- **C 优于 B 说明删尾句有效**：在 cf24/final24 上成立（新增 10→5、复读 1→0）；moved24 上两臂都是 7 条，
  这一组不支持该结论。
- **A 自身退化**：成立，cf24 与 moved24 各丢 2 条事实。按约定，**不能因为 C 不差于 A 就宣告整体通过**。

所以这一轮的结论是：**“原始目标续训”这一步本身有害（A 丢事实），把目标里的错误修掉能把它救回来
（B 84/85、C 85/85），再删掉事实外的尾句能进一步减少新增（C）。但 C 仍不是干净模型**：
cf24 有 5 条新增、4 条语病（其中 3 条继承自起点），final24 有 4 条新增，moved24 有 7 条尾句，独立切片还差 1 条。

**“新增变少是因为句子变短”**也同样没有证据——长短和目标文本同时变了，长度效应没有分离。
本轮能支持的只有“完整修订方案在这个种子和预算下优于保守修订”，不能拆出是哪一部分带来的。
