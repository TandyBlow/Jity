# 确定性事实进入主世界页的回合记录

日期：2026-11-06。**不训练、不启用模型句、不补关系字段。**只读：页面不写回回合记录，适配器只读打开库。

## 1. 接入正式读取链路

后端新增只读接口 `GET /world/facts/{worldId}/{pointId}`（`world-server` 提交 `005ea5b`），挂在
`install_world_routes` 里，和现有世界接口同一个进程。页面不再需要另外启动 `preview_server.py`。

接口返回：结构化增量、展示句、缺口、未展示项。三件事写死在实现里：

| 情况 | 行为 |
| --- | --- |
| `WORLD_FACTS_ADAPTER` 未设 / 文件不存在 / 导入失败 | **503 + 原因**，绝不出句 |
| `WORLD_SQLITE_PATH` 未设 / 库不存在 | **503** |
| 点位不存在 | **404** |

也就是说：**部署错了会报错，不会显示成“这一回合没有变化”。**

适配器本身复制进后端了吗？没有。它仍住在 `experiments/world-components/adapt_facts.py`，
后端按路径加载——这样只有一个适配器副本，不会出现两个实现漂移。

## 2. 接入回合展示

每个回合行下面直接列事实句，三种状态分开：

| 状态 | 页面写法 |
| --- | --- |
| 有事实 | 直接列句子，例：`周宁的理智下降（10→8）。`、`周宁从走廊到门厅。` |
| 任务未展示 | `存在尚未展示的任务变化（没有被当作“没有变化”）。` |
| 恢复失败 | `该点位事实暂无法恢复：<原因>` |
| 空增量 | `第N点没有实体变化。`（由适配器给句） |
| 根点 | **不显示**——根点不是回合，说“没有变化”只会误导 |

来源信息保留在每行的“来源”折叠区（事实、缺口全文）。事实在两条路径上取回：每回合叙事事件到达后取一次，
以及提交完成后的整页重建再取一次（后者保证刷新续接后仍然正确）。

## 3. 完整使用流程验证

**隔离测试世界**：`.local/ws-facts-005ea5b`（`world-server` 的 `005ea5b` 检出，干净、不含其他人未提交的改动）
+ 独立 SQLite `artifacts/next-runs/integration-r1/world.db`，由页面自己新建。

用页面上的正常命令产生变化：

| 步骤 | 命令 | 产生的增量 | 页面显示 |
| --- | --- | --- | --- |
| 0 | （新世界） | 根点，无 Δ | 不显示任何事实 |
| 1 | `完成压力试验` | `sanitySet 8` + `tasksAchieved` + `personalityChanges` | `周宁的理智下降（10→8）。`、`周宁：经历压力试验后更谨慎。`、`存在尚未展示的任务变化…` |
| 2 | `走到门厅` | `positionSet hall` | `周宁从走廊到门厅。` |
| 3 | `完成压力试验`（任务已消耗，规则拒绝） | `{}` | `第3点没有实体变化。` |
| 4 | `走到走廊` | `positionSet corridor` | `周宁从门厅到走廊。` |

再比对页面文本。

## 4. 一个必须说清的限制：外貌变化还没有正常操作路径

规则词汇表只产出四种增量（`rule-facts.ts` 第 144–152 行）：

```
positionSet / sanitySet / tasksAchieved + personalityChanges
```

**没有任何命令会产出 `appearanceChanges`。**所以本轮页面流程覆盖的是移动、理智、性格描述、空增量；
外貌变化只能靠夹具（`adapt-facts` 那批）。展示路径本身是共用的（外貌和性格都渲染成「主体：原文」），
但“外貌变化经由玩家操作产生”这件事，本轮**没有验证**，需要一个会写外貌的规则或输入源。
