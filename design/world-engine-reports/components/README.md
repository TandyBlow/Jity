## 目标与已确定边界

用户要求完整实现[原设计](../../browser-world-state-workflow.md)，先确定组件结构、哪些工作需要小模型及其候选。目标是每个模型几十M到几百M；组件职责可以先确定，具体权重在专项验证后定型。完整能力待办见[实施方向](../full-design-implementation-direction.md)。

- 程序继续负责时间、顺序、骰点、身份、确定性校验、应用、保存与恢复；Python是唯一状态计算权威。
- 模型承接行动、反应、结果、状态候选、继续判断和叙事等语义职责。任务拆小，不删减原功能，不把所有人物判断改成固定命令或规则效果。
- 多个任务可以共享同一编码器/生成骨干，不要求每个组件独占一份模型权重。
- 首批聚焦叙事：程序提取已提交事实 → 模型选择内容 → 模型组织表达 → 小生成模型成句 → 事实核对。保留选择、省略和视角要求，不以逐条复制固定短语作为最终目标。
