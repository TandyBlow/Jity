# 单事实训练数据扩容实验（2026-11-04，作业 238159）

问题：用更多事实绑定组合替代反复曝光，能否减少归属、方位、对象绑定和模板回退错误。

## 1. 材料

| 项 | 值 |
| --- | --- |
| 新增训练单元 | **80**（5 类 × 8 对，每对只改一个关键事实、目标随之改变） |
| 确认单元 | **40**（5 类 × 4 对），生成前冻结，不参与训练与选点 |
| 隔离 | 确认集与训练集按（种类、主体、动作文本）逐条比对，0 重叠（`no_change` 不参与该比对） |
| 正文引用 | 新增训练单元写全目标；确认集只写事实、必述项和评分规则，仅“无变化”单元预写参考句 |
| 校验 | 主体、地点、物件全部在世界表内；目标无数字、无代词开头、无重复；0 问题（`expand_pairs.py` 断言） |

冻结哈希：`n4-expand-freeze.json`（训练 80 `0ec054e9d1bb`、确认 40 `f5b22b3a6d9f`、训练脚本 `87b53a7c3fd4`）。

## 2. 训练

从原基座初始化，输入 A、AdamW、lr 3e-4、fp32、seed 20261102 全部不变。每批固定 **4 条原训练 + 4 条新增**，最多 **2880 次更新**（固定预算，不再要求原样本曝光 120 次）。

| 项 | 值 |
| --- | --- |
| 原训练单元 / 新增 / dev | 190 / 80 / 14 |
| 每次更新目标 token（原 4 + 新 4） | ≈ 73 + 52 |
| 实际更新 | 2880 |
| 训练耗时 | 164.4 s |
| 峰值显存 | 2.56 GB |
| 评估节奏 | 每 240 次更新（共 12 次） |
| 选中检查点 | **step 480**（dev 0.9561） |
| dev 曲线 | 0.9955 → **0.9561** → 0.9905 → 1.0353 → 1.3622 → … → 1.10 |

引用时要注意：基线臂选在 epoch 10（120 次曝光），本臂选在 step 480，**训练量不同**，dev loss 不能直接比高低。

## 3. 确认集（主要证据）

40 个单元全部完成，**40/40 表达事实**：五类各 8/8，包括动作执行者、所有者、容器内外、对象绑定和“变化 / 无变化”。

这个结果要打个折：确认集的事实都是单句短动作，与新增训练单元写法接近，**属于“同族新组合”而非“未见表达结构”**。它说明扩容把这一类写法教会了，不能说明泛化到复杂事实。

## 4. cf24 v2（检查退步）

| | 冻结基线 | 扩容臂 |
| --- | --- | --- |
| 事实支持 | 80/85 | **81/85** |
| 遗漏 / 矛盾 / 归属错 | 2 / 1 / 2 | 1 / 1 / 2 |
| 有未支持新增的源 | 4 | **1** |
| **完整源干净** | 16/24 | **20/24** |
| cf24 总延迟 | 12.02 s | 8.38 s |

**得**：`t01`、`t08`、`t12`、`t15`、`t16` 转干净。其中正是回归案例里的两类：
- `t08` 两处归属错修好（顾行舟的绕缆绳、外套都归位）；
- `t16` 容器内外修好（内层写成内层，不再是外层）；
- `t01`、`t12`、`t15` 的未支持新增（“又回到档案馆”“抱着一叠鱼筐”“抱着木桩”）消失。

**失**：`t20` 变脏（f0 从支持变成归属错——“雾堤上的风吹歪，玻璃罩被风吹歪”，警示灯这个主体丢了）；`t23` f1 从支持变成矛盾（“铜灯罩上的结了锈”，把铁链的锈挂到灯罩上）。

按事实逐条：得 3 条（`t08` f1/f3、`t16` f1）、失 2 条（`t20` f0、`t23` f1）。

## 5. 判定

按预设的继续条件（新样本完整表达能力提高 + 旧集没有明显退步）：

- 新样本：40/40 全部表达，**提高**；但样本与训练分布接近，证据强度有限。
- 旧集：干净源 16 → 20，支持 80 → 81，**没有明显退步**；两处新错误都属于“物品类主体”的绑定（警示灯、铁链），不是原先回归的五类。

**结论：可以继续扩容，但下一步要补“物品类主体 + 多对象同源”的组合**——两次丢失都发生在物件作主体、同源里还有别的物件时；现有 80 条里这类样本只有 `tb` 少量，且没有成对覆盖“物件 A vs 物件 B”。

同时明确：这一轮只证明**这类单句写法的覆盖率提升**，不证明模型学会了泛化到未见结构，也不涉及衔接。
