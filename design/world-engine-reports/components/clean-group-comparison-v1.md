# 干净监督下的单事实／句组对照 v1（预登记）

状态：材料与预算先冻结，再训练一次。只训练组级成句模型，不训练组织模块；不恢复历史四臂，不训练整段计划控制。

## 1. 问题

在契约一致、目标完整覆盖事实的监督下，**组内联合表达**是否仍比**逐事实表达**更容易漏写、串主体和复读？

## 2. 材料

- 36 源，沿用现有源级划分：20 train / 6 dev / 10 固定留出。不新增事实。
- 每源使用已有的非“全拆”合法计划（原 `controllability-v1` A 计划）；36 源都有至少一个实际合并组。
- 两臂：
  - **A**：每次调用一条事实；目标 = 该事实的独立短句（姓名补回）。
  - **B**：每次调用一个计划组；目标 = 该组的原有正文（组内允许合法主语省略）。
- 两臂的目标来自同一套既有事实短句；A/B 的差别只在“是否把一个组拆成多次调用”以及组内合法省略。`随后` 不写进目标，由程序在装配时插入。
- 36 源逐条检查：每条事实恰好出现一次；每个目标有姓名和事实内容；无代词、无数字；A 的目标逐条补回姓名；B 的目标完整保留组内全部事实。
- 计数：A 调用 train 74 / dev 24 / holdout 37；B 调用 42 / 15 / 20；多事实组 23 / 8 / 13。

## 3. 训练

- 同一可确认基座 Randeng-T5-77M（权重哈希见冻结记录）；两臂都从该基座初始化。
- 同一输入模板：场景＋本组事实＋组序；A 的本组只有一条事实，B 的本组是一个计划组；不传整份计划。
- 1 次调用/步，梯度累积 4，480 步＝**120 次优化更新**；两臂都在第 120 次更新比较，**不选点、不早停**。
- lr 5e-4，warmup 12，seed 13，fp32；input 512、target 128；greedy，max_new 128；无 wall-clock 超时。
- 记录每臂的实际调用数、事实曝光、目标 token 总数、每更新的事实/ token；不声称两臂训练量完全相同。
- 组间句界、并行连接和 `before` 的“随后”全由程序装配；模型不负责边界。

## 4. 评价

固定留出 10 源、13 个多事实组。逐例比较 A 的逐事实装配与 B 的组级输出：

1. 必述事实是否写出；
2. 主体／对象绑定是否正确；
3. 语义重复（≥12 字重复片段，人工确认）；
4. 未经支持的新增；
5. 表达偏好（B 更自然/连贯、A 更好、相当）。

**主指标是成对得失**：某个多事实组上，B 是否出现 A 没有的漏写、串主体、复读或加料；反过来 A 是否有 B 没有的错误。单事实组（组内只有一条事实）只作保持性检查，不能算联合表达收益；程序保证句界也不算模型收益。

预登记通过条件：

- 13 个多事实组上，**B-only 安全损失 = 0**（B 没有 A 没有的必述/主体对象/语义重复/未支持新增错误）；
- B 的表达胜出不小于表达失利；
- 单事实组不出现明显退步。

未通过则结束当前材料和配方下的组级成句路线；通过也只说明有了可用的下游接收者，不证明组织模型或整个 workflow 有效。

## 6. 执行结果（2026-11-06）

两臂各 480 步 / 120 次更新，固定同一点，无选点。A 采样 480 事实 / 5,510 target token（4.0 / 45.9 每更新）；B 采样 844 事实 / 8,712 token（7.03 / 72.6 每更新），B 的实际曝光更高，不能称训练量相同。固定留出 13 个多事实组：**B-only 安全损失 2**（`t24` [f2,f3] 漏沈砚扶灯，`v20` 漏理智），表达 B 胜 10、A 胜 2、平 1；7 个单事实组无退步。A 自身也有错误（`t24` 对象/语法、dev `train-r3`），B 在 dev `t12` 有一次串主体；holdout B 无串主体、无复读、无未支持新增。按预登记安全门未通过：当前材料和配方下的组级成句路线结束，不训练组织模块。详见 `artifacts/world-components/organize-wording/clean-group-report-v1.md`。
