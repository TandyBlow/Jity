## 运行前固定四臂

| 臂 | 分词/装箱 | 编码执行 |
|---|---|---|
| reference | 原慢分词器；装箱后再分词定位事实 | 显式SDPA，核对原批分数 |
| packed | 原慢分词器；每段只分词一次，同时保存事实跨度 | 同SDPA |
| fast | 同词表的BertTokenizerFast，一次批量处理前缀与事实，同时保存跨度 | 同SDPA |
| eager | 与fast完全相同 | 同权重的eager注意力实现 |

前20个旧开发来源组只做分词/装箱字节一致性检查，无新增模型推理或训练；优化后的value/facts/windows（含token ID、类型、顺序、跨度）须逐项等于reference，任何差异在业务推理前停止。每次计时重新分词和编码，不跨题或跨次缓存。慢分词仍是保留的对照路径，优化沿用同一个原子事实装箱工具，不复制另一套语义流程。

实际推理仅原4个已公开开发题，每臂每题5次，共80项/预期320窗口。四臂按原正反顺序交替，所有臂使用同一个追加日志流程，包含输入、张量、编码、池化、头、结果flush/fsync及尾部遥测。无warmup业务调用、无挑最快次；模型/分词器加载和20组一致性核验列准备阶段。

reference/packed/fast需逐值复现原event2概率；eager因浮点计算顺序可能不同，运行前固定最大绝对概率差≤1e-6、目标/行动判定必须完全相同。逐值相同和容差内相同分开报告，超限/判定变化保留失败，不按结果改容差或阈值。eager只是执行候选，不能因权重一致就假定数值完全相同或速度更快。
