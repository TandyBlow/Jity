## 共同契约

`short_contracts.Completion` 有三种互斥状态：`result(value)` 完成有结果；`empty()` 完成无结果；`incomplete(reason)` 未完成。错误、缺资料、取消、截断、超时、未输出 end、资源暂停不能转为否定结果。中间已完成材料留在尝试日志和进度快照；失败返回不暴露一个可被误采纳的部分结果。

`ModelSession.call(component,payload)` 绑定完整输入、工作身份和模型/权重/适配/分词/精度/实现身份；每次尝试先记 start，保留原始返回、错误、耗时及重试。缓存默认关闭，开启时按全部身份与实际输入哈希命中。每个模型组件拿完整适用上下文，程序不以距离、已行动、局部任务或字数裁剪来提速。外层既有监督器负责进程资源上限；迟到结果还须通过 epoch、身份及耗时检查。

`FrozenAction`/`FrozenValue` 防止冻结后改写。哈希证明字节绑定，不证明语义正确或服务授权。模型审核 pass 只记录为模型判断；不能升级为人审通过。

## A/B/C 兼容提案及缺口

外部 action 的 act(text)/skip、targets、按成员 results、六阶段 updates、初始模板、time、pointPlan、continuation 的字段保持原样。内部 Completion、片段、审核、映射、模型身份不塞入闭合 wire。实验 action freeze 不声称已得到 A 的 discover/extend 接受。

1. **B 输入装配**：`schedule.ts`/`runtime/model-port.ts` 对新适配器提供完整组行动、拒绝/已行动关系的实际骰点/资格、任务/有效记录、消费状态及绑定版本。当前 `members[].rollRefs` 已带 `targetId/rollId/result/eligible/admitted`，包含拒绝准入值；新实验还要求原 `RollOutcome` 的规则/阈值、来源/trigger/资格基线绑定及闭组目标集合，以检查完整性，不能只重命名字段就称接入完成。实验拒绝缺字段，不擅自扩展公共协议。
2. **A 阶段预览**：D 基线继承的旧 `SettlementGroup` 把 personalities/sanities 配对放在 wire 校验，U5 后的部分候选会被拒绝；实查远端 A `world-server@fc60a603` 已将完整规则移入 adoption 校验，原 `preview_point` 支持部分阶段。提案改为对齐这一已有修复并复用固定 A 只读纯逻辑，不新增 API。不得用旧理智填空。离线预览不等于正式服务接入。
3. **C 正式事实**：`committed_packet(before,after,verify_committed=...)` 只接目标点及明确前驱的 GetStateData；检查同世界、版本、初始态不变，必须由 A 适配器核服务来源/摘要/原始 Δ 回放。保留完整 before/原始 delta/after/合法 anchor，不使用候选、预览、评审标签。现有 `committed-narration.ts` 的窄事实投影拒绝许多合法物品/外貌/非成套任务变化；需 C 扩展支持，不能静默丢事实。
4. **时间点提交**：六阶段单元先 stage，所有行动槽位、所需单元、必要时间扫描都完成并收到 A seal/commit 回执后才能创建 C 输入。C ready 后处理尚有的合法关联段；原轮及关联段全完成再 D07。
5. **叙事失败**：世界已提交保持不变。C retry 使用同一个 packetHash，独立本地尝试 generation；模型完成不等于正式 ready，必须经过 A 接受回执及服务 claim/门验证 callback。旧请求、旧 generation、取消后或恢复前的迟到输出不能释放新 gate。已验证的新 epoch 可重绑定恢复，但旧 ready 不能直接放行新请求；冻结材料不重生成/掷骰。
6. **结果保留缺口**：D05 需要长期保留但无法对应现有状态字段的事实以 `gap` 停止交接。映射表只为当前实验审查与候选覆盖，不成为长期事件真值。

A/B/C 的产品目录本次不修改。字段级兼容方案见 [交接提案](short-compatibility.md)。以上提案有 D 侧反例测试，正式实现与真实 C 模型均未接入，叙事质量未验证。
