# 边界数据 v2 臂：40 双项（2026-11-04，训练一臂）

先按你的修正改了评分边界：**按具体事实的授权判断，不按动作词一律判新增。**

- `状态变化｜放松` 允许可感表达：`沈砚松开手，才发现自己一直提着的那口气落回去了`、`沈砚的呼吸慢慢匀下来，胸口那点发紧的感觉散了` 都**不再计入新增**。
- 同一句“松开手”若出现在只授权移动的单元里，仍算新增。
- 现有案例按所属事实重判：u240 新增单元 14→**13**，b240 13→**12**；**源级干净数不变**（u240 89/102、b240 85/102），因为两个涉事源在别处仍有问题。

| 硬门 | 结果 |
| --- | --- |
| 必述不退步 | **未过**：213/215 → 202/215，其中 3 条是明确缺失（含一条事实完全写错） |
| 语义重复不增加 | **未过**：0 → 2 处字面重复（另有打结句），真实回合 0 → 6 |
| 未授权新增不增加 | **未过**：13 → 约 30 个单元 |

按你的规则：**暂停这类边界数据扩容**，结果保留，不再沿失败句逐轮补样本。

## 6. 这轮说明了什么（只写记录支持的）

1. **双项数据能修双项遗漏**，这一点成立（确认集 40/40、两次检查点都清）。
2. **但同一批数据把模型推向“写更多”**：40 条双项目标比单项长，模型在诊断集上开始大量续写场景与动作（推开堤面、雨声被关在身后、袖口带着铜灯），并出现事实行被抄进句子的错位。
3. **真实回合的重复回到 u240 水平**（0 → 6），说明“减少重复”的收益不是随数据单调增长的，它和双项比例互相拉扯。
4. 因此不能把这一臂解释成“边界数据无效”，也不能解释成“多训几步就好”；它呈现的是**目标集改善、旧诊断集回退**。旧诊断集与训练数据同属一个虚构世界与同一事实种类，不宜称为“分布外”——那会掩盖真实原因。
