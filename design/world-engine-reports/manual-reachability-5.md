# 人工可达性验证：5 个目标稿（2026-11-04，不运行模型）

目的：先确认“希望模型做、而现有规则做不到”的改善**是否真的存在**。这 5 例用于定义任务，不是测试集。每例保留当前 A 稿，另写一版更自然、且不越授权边界的目标稿，并逐处标出来源。

授权边界按现行契约：只用事实、`地点`／`场景` 给出的内容与 `地点可见` 里物件的在场；关系只能用已授权的 `before`；不新增人物、物件、动作、因果、目的、感知；事实顺序不变。

> **v2 更新（2026-11-04）：** 本文的逐段归类与新的权限边界见 [`expression-contract-v2.md`](expression-contract-v2.md)。按 v2 的“完整授权描述”口径，t01 的“小雨落在天窗外/在铜灯下”、v02 的“还没散”判为超出 v2；跨主体并列在 v2 中已放开（t19/v05 不再需要“先改授权”），事实重排仍不放开。本文保留当时的判断作为记录。

## 1. 同主体：t01（沈砚三条，同一人）

- 事实：`补全潮汐簿缺页`／`指尖沾了墨`／`把簿子合上推到桌角`
- 授权背景：地点=潮汐档案馆；可见=潮汐簿、铜灯、干纸、墨、天窗、长桌、门槛；场景=夜；小雨；铜灯

**A 稿**

> 沈砚把潮汐簿缺的那页补全，指尖沾了墨，把簿子合上推到桌角。

**目标稿**

> 小雨落在天窗外。沈砚在铜灯下把潮汐簿缺的那页补全，指尖沾了墨；他合上簿子，推到桌角。

| 改善来源 | 具体改动 |
| --- | --- |
| 背景选择与落点 | 「小雨」（场景）＋「天窗」（可见）开场；「在铜灯下」（可见＋场景）落到动作前，而不是堆在句尾 |
| 指代 | 第三句的「沈砚」改「他」——全段只有沈砚一人，指代唯一 |
| 措辞与断句 | 一句三个分句拆成「主句＋分号＋短句」，动作节奏分开 |

## 2. 跨主体：v02（阿棠／顾行舟）

- 事实：`阿棠把银鳞鱼按大小分开装进鱼筐`／`顾行舟把抹布拧干`／`顾行舟手背上沾了鱼鳞`
- 授权背景：地点=早市；可见=银鳞鱼、鱼筐、案板、抹布、帆布棚、石板；场景=清晨；薄雾；棚下散光

**A 稿**

> 阿棠把银鳞鱼按大小分开装进鱼筐。顾行舟把抹布拧干，手背上沾了鱼鳞。

**目标稿**

> 清晨的薄雾还没散，棚下散着光。阿棠把银鳞鱼按大小分开，装进鱼筐。顾行舟把抹布拧干，手背上沾了鱼鳞。

| 改善来源 | 具体改动 |
| --- | --- |
| 背景选择与落点 | 「清晨」「薄雾」「棚下散光」三个场景片段合成一句开场；顺序放在人物动作之前 |
| 措辞与断句 | 「按大小分开装进鱼筐」→「按大小分开，装进鱼筐」，停顿更清楚 |

这一例的收益很薄：**A 稿本身已经通顺**，目标稿只是补了场景开场。要再进一步（“两人各忙各的”那种对照感）就得加“ meanwhile ／与此同时”，而**同时关系未授权**。

## 3. 跨主体交替：t19（阿棠→沈砚→阿棠→沈砚）

- 事实：`阿棠袖口沾了鱼鳞`／`沈砚外袍下摆沾了泥水`／`阿棠把银鳞鱼装进鱼筐`／`沈砚把油纸伞收拢靠在摊棚边`
- 授权背景：地点=早市；可见=银鳞鱼、鱼筐、油纸伞、帆布棚、案板、石板、白汽；场景=清晨；薄雾；棚下散光

**A 稿**

> 阿棠的袖口沾了鱼鳞。沈砚的外袍下摆沾了泥水。阿棠把银鳞鱼装进鱼筐。沈砚把油纸伞收拢靠在摊棚边。

**目标稿**

> 清晨的薄雾里，棚下散着光。阿棠的袖口沾了鱼鳞，沈砚的外袍下摆沾了泥水。阿棠把银鳞鱼装进鱼筐；沈砚把油纸伞收拢靠在摊棚边。

| 改善来源 | 具体改动 |
| --- | --- |
| 背景选择与落点 | 同 v02 的场景开场 |
| 措辞与断句 | 四句两两并列（前两句用逗号、后两句用分号），读者能看出“两人各做了两件事” |
| **契约不允许** | 真正读起来最顺的是**按人物归并**（阿棠两条、沈砚两条），但那要**重排事实顺序**——未授权，不能做 |

## 4. 多对象：v05（叶知微／沈砚，铜油与灯罩）

- 事实：`叶知微袖口沾了铜油`／`沈砚手背上沾了铜油`／`叶知微把灯罩擦得透亮`／`场景｜无变化`
- 授权背景：地点=旧灯塔>塔顶；可见=铜灯罩、灯芯、抹布、擦铜油、铁链、备用灯芯；场景=夜；夜雾；塔顶铜灯已点亮

**A 稿**

> 叶知微的袖口沾了铜油。沈砚的手背上沾了铜油。叶知微把灯罩擦得透亮，玻璃上不再有雾。塔顶的灯还亮着，什么也没有再发生。

**目标稿**

> 叶知微的袖口沾了铜油，沈砚的手背上也沾了铜油。叶知微把灯罩擦得透亮。塔顶的灯还亮着，什么也没有再发生。

| 改善来源 | 具体改动 |
| --- | --- |
| 措辞（去掉加料） | 删掉「玻璃上不再有雾」——它不在事实里，是 u240 的加料 |
| 措辞与断句 | 两条同类事实用「也」并列成一句，省掉重复的「沾了铜油」 |
| **契约不允许** | 并列的是**两个不同主体**，现行契约只允许同主体合句，所以这一版目标稿在现有规则下产不出来 |

## 5. 带合法 `before`：train-r1（关系 f2→f3）

- 事实：`沈砚袖口沾了雨`／`沈砚指节发白`／`顾行舟斗篷下摆湿了一片`／`叶知微鞋底沾了泥`／`叶知微袖口湿到肘部`
- 授权关系：f2 之后可写「随后」（后一条是 f3）
- 授权背景：地点=潮汐档案馆>长桌；场景=夜；浓雾

**A 稿**

> 沈砚的袖口沾了雨，指节发白，指节发白。顾行舟的斗篷下摆湿了一片。随后，叶知微的鞋底沾了泥。叶知微的袖口湿到肘部。

**目标稿**

> 浓雾里，沈砚的袖口沾了雨，指节发白。顾行舟的斗篷下摆湿了一片。随后，叶知微的鞋底沾了泥。叶知微的袖口湿到肘部。

| 改善来源 | 具体改动 |
| --- | --- |
| 措辞（去重复） | 删掉「指节发白」的第二遍——这是 u240 的复述缺陷 |
| 背景选择与落点 | 「浓雾」（场景）放句首，作为整段的环境 |
| 保持不动的 | f3／f4 虽然同主体，但 f3 是关系端点，**保留句界**，不合并——这正是更正后的契约要求 |

## 7. 这些例子说明了什么

1. **能稳定改善的部分，集中在“措辞与断句”和“场景片段落到句首”**。前者是改写，后者是从授权片段里挑一个开场——都不需要新信息。
2. **真正让段落变顺的两件事，现有契约都不允许**：t19 想按人物归并（要重排事实），v05 想把两条同类事实并列（要跨主体合句）。这两条如果放开，改善是明显的；不放开，就只能做很小的润色。
3. **“段落划分”在 5 例里没有产生价值**：这些源最多 5 条事实、都是一个场景里的一串动作，切成两段反而割裂。
4. 有一类改善**不是组织问题而是上游缺陷**（v05 的「玻璃上不再有雾」、train-r1 的复述），人工改起来是一删了之，但它属于生成层该修的，不该算进“组织模型”的任务。

## 8. 据此的下一步建议（未执行）

- **可为的小任务**：从授权片段里选开场与落点（背景选择）＋ 断句与指代调整。范围窄、可机械校验（片段必须来自白名单、指代必须唯一）。
- **需要先改授权再做**：事实重排、跨主体并列。这两条不放开，模型只能做润色，收益上限很低。
  - v2 已放开跨主体并列；这一条现在只对**事实重排**仍然成立，跨主体并列不再属于“需要先改授权”。
- **不建议**：再做一个“整合器/规划器”去选合句——同主体合句规则已经拿完，这轮再次确认。
