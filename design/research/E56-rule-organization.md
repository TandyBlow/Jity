# E56 规则组织：句子干净了，但"按角色聚簇"才是缺的那一步

**Question.** 在规则基线之上加同主语合并、代词、连接词与分段，能否从事件日志走向叙事？

**Setup.** 161 个输入，同一事实源。规则：玩家自己的结算事件排最前；结果标签并入句子
（却没有成功／只完成了一部分）；跳过缺主语与括号残片；重复时间行只留一条；同角色连续
从句尝试合并（又+谓语）并按句数分两段。

**Results.**
- 660 句、19,712 字（现役 98,037 字的 **0.40**）；句子语法成立、主语正确、无新增实体。
- **合并 0 次、连接词 0 次**：结算记录与事实块里同一角色的动作从不连续出现，规则没有
  可合并的相邻对象。

**Interpretation.** 表层组织规则在这批输入上不起作用，因为缺的是**内容组织**：把同一
角色/同一事件的事实聚到一起，再决定句序与连接。下一步应先做"事件聚簇"（按角色、地点、
因果链），再在簇内做合并与指代——这正好是目标里"信息组织"那一层，且可以用人工正确的
中间结果先验证。
