# E33 plan→prose v0：0.84M 字符级生成器（负结果）

**Question.** 在人工计划（人类选择 + 人类顺序）下，一个 0.1–15M 的微型
生成器能否把计划写成正文、达到 E31 的地板之上？（goal 阶段三首实验）

**Setup.** `plan_to_prose.py`：348 段 v13 语料，输入为计划（选中从句 + 类型
标签），输出为正文；字符级 Transformer（d=128、4 头、3 层，**839,644 参数**），
60 轮、AdamW、teacher-forced 训练；按事实集哈希分组留出（263 训练 / 85 测试）；
贪心解码；固定种子 20261128；全部 85 条生成写入
`plan-to-prose-samples.jsonl`。

**Results.**
- 训练 loss 2.55 → 0.057（263 段上明显过拟合）。
- 留出 charF1：均值 **0.332**（min 0.017、中位 0.304、max 0.55）——数值上高于
  E31 的全部地板（程序 0.208 / 选择 0.265 / oracle 拼接 0.290）。
- **但样例质量不合格**：多条生成退化为「路明非。」「路明非没有挪位置。路。」，
  或出现碎片拼接的乱句（把事实片段以错误的语法粘连）；"高于地板"主要来自对
  高频短语的复制，而不是可读叙事。
- 误差分解（`error-split.json`，charF1 口径）：选择模型增益 +0.057、生成器在
  oracle 计划上的增益 +0.042、距人类正文仍有 0.668。**charF1 奖励复述、掩盖
  错误**——这个分解只作趋势参考，不能当作质量结论。

**保真度评分（`fidelity_eval.py`，85 条全部匹配）.** 计划覆盖率均值 **19.7%**
（生成文本只含计划内容词的约五分之一）；每条生成平均出现 **17.2 个计划外词**。
charF1 与保真度因此方向相反：重合来自对高频短语的复制，计划内事实大量缺失、
计划外内容大量出现——生成器并未"按计划写"。

**Interpretation.** 朴素字符级 plan→prose 是负结果：overlap 指标过门而正文
不可用。下一步三项必须一起改：
1. 评价先换：以"计划事实覆盖率 / 矛盾 / 新事件"的保真度指标为主，charF1 为辅；
2. 解码结构：编辑式（保留/删除/替换/插入）与短语级指针，而非自由逐字生成；
3. 数据：263 段对 0.8M 参数已过拟合——要么扩语料，要么把生成器压到更小并用
   检索/编辑约束（与 goal 的 ≤15M/单链路 ≤30M 预算一致）。

**Caveats.** 单世界单风格；85 段分组留出；charF1 对词序与错误不敏感；尚无
人工质量评级；结论仅针对该配置。
