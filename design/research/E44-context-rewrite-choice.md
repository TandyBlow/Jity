# E44 带上下文的改写选择：上下文只比"最常用改写"高 1 个点

**Question.** 同一个短语在不同句子里会被改写成不同说法。给模型"事实从句 +
上一句正文"的上下文，能不能选对改写？这是对"措辞改写需要上下文"的直接检验。

**Setup.** `build_replace_pairs_ctx.py` 在 oracle 计划上按**从句**对齐，抽出
7,429 条（src→dst）改写对，每条带所在事实从句与目标文中的上一句，覆盖 348 个
段落。`rewrite_rank.py` 按段落切分（6,317 训练 / 1,112 测试），对每个测试短语
取训练集中同 src 的改写作为候选（覆盖率 0.936），比较四个基线：
1) 原样复制；2) 同 src 的最常用 dst；3) 上下文余弦检索（从句+上一句的字符
bigram）；4) 10 特征逻辑回归排序（频次、上下文余弦、词长差、上一句有无、
句位、dst 与从句/上一句的重叠、从句相似度）。

**Results.** exact / charF1：
- 复制：0.000 / 0.048
- 最常用改写：**0.104 / 0.315**
- 上下文余弦检索：0.092 / 0.319
- 学习排序：**0.116 / 0.325**（比最常用改写 +1.2pt exact / +1.0pt charF1）

**Interpretation.** 上下文特征确实带一点信号，但词级改写选择主要被"这个短语
最常见的改法"解释；纯上下文相似度甚至不如频次先验。这和 E37 并不矛盾：E37
说明**脱离上下文无法改写**，E44 说明**只加一层浅上下文也不足以决定改写**。
要验证"上下文是关键"，下一步得做句级联合：输入整段事实 + 已写正文，输出对
整句的编辑序列，而不是在孤立短语上选候选。

**Caveats.** 改写对来自逐从句对齐，含少量错配噪声；特征手工设计、未调参；
指标是短语级 exact/charF1，不是整句可读性；语料里真正相邻回合的"上一段正文"
只有 42 对，本实验的"上一句"用的是同一次输出内的前一句。

**Artifacts.** `build_replace_pairs_ctx.py`、`replace-pairs-ctx.jsonl`、
`rewrite_rank.py`、`rewrite-rank-summary.json`。E44。
