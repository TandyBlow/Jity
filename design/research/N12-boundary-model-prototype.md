# N12 句间组织微模型接入原型：事实句 13.08 → 10.12 句/point，片段零丢失

**Question.** N10 的句界模型能不能直接用在规则渲染器上：把零散的事实句合并成更少的句子，
同时不丢任何片段？合并后的正文比“每片段一句”强多少？

**Setup.** 逻辑回归句界模型（字符二元组 + 前后片段，约 2 万非零特征，训练集为 N10 的
267 个标注片段对）应用到 161 个输入的**事实片段**；结算结果仍每条一句，时间行收尾。
同一句内用“，”连接，句间用“。”。所有片段按原文输出，不增删。

**Results.**
- 每 point **10.12 句**（规则现状 13.08），337 字/point（规则 330 字），
  **缺失片段 0**（2,151 个片段全部出现）。
- 与 N10 的独立口径对照：按内容分组留一的句数是 **10.55**，本页 10.12 是同一模型对
  训练分布的再应用，乐观约 0.4 句；两个数都显著低于 13.08。
- 样例：
  `右墙贴着赛区图，器材棚门敞开，巷子尽头的低墙挡住庭院视线，墙角留下新鲜的演习弹红痕。`
  `屋里有路明非的演习背心，背心前襟完好，没有演习弹痕，胸袋能放一只弹匣，肩上没有阵营识别带。`
  `屋里有赛区路线图，图上画出庭院、东西回廊、跨溪小桥、钟楼与白线撤离路，地下检修通道用虚线标注，未标。`

**Interpretation.**
- 句间组织从“研究探针”走到了“能接进渲染器”：一个 2 万维线性模型把事实句合并掉 23%，
  事实与结果一条不少。这正是目标里“句子结构预测、片段选择与语法组织”的第一块可交付件。
- 它只解决“哪些事实并进同一句”，没有解决：并句用“，”还是“；”、每句的主语、句间连接词、
  指代。下一版应共享同一片段编码器，加主语与连接头；但按评审意见，先要把参考集的
  选择策略与标签冲突降下来，再训练联合模型。
- 目前仍在离线原型：TS 页面里的规则臂还没接这个模型（需要 ONNX 导出与浏览器一致性
  验证）；在接入前，页面用的仍是“每片段一句”。

**Caveats.** 10.12 是同分布再应用，不是独立测试；模型只在 63 种上下文上训练；只处理
事实句，结算结果仍逐条；没有主语/连接/指代；未做 ONNX 与浏览器一致性。
