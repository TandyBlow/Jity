# N16 人工自然正文 + 来源检查：8 个子句、13/15 片段、0 问题

**Question.** 先不训练模型：一份人工写好的自然正文，能不能被程序检查出“有没有编造、
有没有漏掉必须写的结果”？这套检查能否成为后续模型的正确答案与评价标准？

**Setup.** 取 N15 的同一个 point，按“子句 + 来源片段”标注一份自然正文
（`natural-reference.json`）：每个子句写明它用了哪些片段。`check_natural.py` 检查：
1. 子句里出现的人名、数字必须出现在它的来源片段里（编造检查）；
2. 子句与来源片段的二元组覆盖率 ≥0.5（改写不能脱离事实）；
3. 每条带结果标签的结算片段必须被某个子句使用（漏写检查）；
4. 失败/部分完成的线索词必须出现在正文里（结果极性检查）。

**Results.**
- 8 个子句、使用 13/15 个片段、省略 2 条静态事实（路线图、地下检修通道），
  **0 problems**：无编造人名/数字、每句覆盖率达标、5 条结算结果全部表达、失败线索保留。
- 正文（节选）：`楚子航守住了顶层，顾岚则查看了医护空床。` /
  `路明非的护目镜挂在胸前，镜片没有裂纹，镜带松着；背心里的胸袋能放一只弹匣，肩上没有阵营识别带。`

**Interpretation.**
- “人工正确 → 自然正文”的链路现在是具体的：标注写自然子句并标来源，程序检查编造与
  漏写。自然度来自人的改写（体标记、连接词、主谓化、重排、省略），检查保证改写不越界。
- 这套标注同时给出了模型的目标：输入是片段，输出是**子句序列 + 每句来源**。模型预测
  的是“怎么写”，不是“写不写结果”——结果由策略强制。
- 与句界模型的关系：句界只决定“并成几句”，而这里的目标包含句内改写。后续模型应先
  预测**子句边界与来源分组**，再由受限生成/编辑补上体标记与连接词；两步都对着人工
  自然正文评价，而不是对着 1.7B 的漏写正文。
- 按评审意见，句界模型暂不接入；这份人工正文作为第一批 gold，先扩到 20–30 个 point，
  再谈训练。

**Caveats.** 只有 1 个 point、由我一人手写；0.5 覆盖率阈值是经验值；省略策略尚未写成
规则；检查器只覆盖人名/数字/结果/覆盖率，不检查语法与指代。

check_natural.py,annotation-pilot.json}`。N16。
